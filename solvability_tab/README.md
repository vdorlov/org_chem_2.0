# Модуль «Таблица растворимости»

Самодостаточный модуль: рендерит интерактивную таблицу растворимости кислот, оснований и солей.

## Файлы

- `solvability.js` — логика: рендер, фильтры, поиск, модалка. Экспортирует `window.__renderSolvability(containerEl)`.
- `solvability.css` — стили. Используют CSS-переменные из основного `index.html`.
- `data.json` — данные: катионы, анионы, ячейки с растворимостью и реакциями.

## Как подключить

В основном `index.html` таблица **не грузится сразу**. Подкачивается при клике.

## Формат данных

`data.json`:
- `types` — обозначения: Р / Н / М / — / ?.
- `cations` — катионы (столбцы).
- `anions` — анионы (строки).
- `cells` — ячейки: `"cationId|anionId": { type, name, formula, reaction, note }`.

Ключ ячейки — `{ cation }|{ anion }` в нижнем регистре, например `ag|cl`.

## Обновление данных

Откройте `data.json`, добавьте новую ячейку:

```json
"cu|co3": {
  "type": "insoluble",
  "name": "Карбонат меди(II)",
  "formula": "CuCO₃",
  "reaction": "CuSO₄ + Na₂CO₃ → CuCO₃↓ + Na₂SO₄",
  "note": "Зелёный осадок."
}
