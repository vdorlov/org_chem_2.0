# Блок 8. Задание 34 — Комбинированная расчётная задача

---

**Задание 1.** Этанол → (выход 80%) → ацетальдегид → (выход 75%) → уксусная кислота → (выход 90%) → этилацетат. Найдите массу этилацетата из 100 г этанола.

Ответ:
1. η(общий) = 0,80 × 0,75 × 0,90 = 0,54
2. n(C2H5OH) = 100 / 46 = 2,174 моль
3. По уравнениям: C2H5OH → CH3COOH → CH3COOC2H5 (1 : 1 : 1)
4. n(теор., этилацетата) = 2,174 моль; m(теор.) = 2,174 × 88 = 191,3 г
5. m(практ.) = 191,3 × 0,54 = 103,3 г

**Задание 2.** Метан → (выход 90%) → ацетилен → (выход 80%) → бензол → (выход 70%) → нитробензол. Найдите массу нитробензола из 100 л метана (н.у.).

Ответ:
1. η(общий) = 0,9 × 0,8 × 0,7 = 0,504
2. n(CH4) = 100 / 22,4 = 4,46 моль
3. 2CH4 → C2H2 (2:1); 3C2H2 → C6H6 (3:1)
4. n(теор., C6H6) = 4,46 / 6 = 0,743 моль
5. n(нитробензола) = 0,743 моль; m(теор.) = 0,743 × 123 = 91,4 г
6. m(практ.) = 91,4 × 0,504 = 46,1 г

**Задание 3.** К 200 г 10%-ного раствора гидроксида натрия прибавили 32 г уксусной кислоты. Определите массовую долю ацетата натрия в полученном растворе.

Ответ:
1. CH3COOH + NaOH → CH3COONa + H2O
2. m(NaOH) = 20 г; n(NaOH) = 0,5 моль
3. n(CH3COOH) = 32 / 60 = 0,533 моль — избыток
4. n(CH3COONa) = 0,5 моль; m = 0,5 × 82 = 41 г
5. m(раствора после) = 200 + 32 = 232 г
6. ω(CH3COONa) = 41 / 232 × 100% = 17,7%

**Задание 4.** Смесь этилена и ацетилена объёмом 10 л (н.у.) пропустили через избыток бромной воды. Масса брома, вступившего в реакцию, 80 г. Определите объёмные доли газов в смеси.

Ответ:
1. C2H4 + Br2 → C2H4Br2; C2H2 + 2Br2 → C2H2Br4
2. n(смеси) = 10 / 22,4 = 0,446 моль
3. n(Br2) = 80 / 160 = 0,5 моль
4. Пусть x — n(C2H4), y — n(C2H2):
   x + y = 0,446
   x + 2y = 0,5
5. y = 0,054 моль; x = 0,392 моль
6. φ(C2H4) = 0,392 / 0,446 = 87,9%; φ(C2H2) = 12,1%

**Задание 5.** При сгорании 5,4 г органического вещества получили 8,8 г CO2 и 3,6 г H2O. Вещество реагирует с натрием с выделением водорода и не реагирует с гидроксидом натрия. Определите формулу.

Ответ:
1. n(CO2) = 0,2 моль; n(C) = 0,2 моль
2. n(H2O) = 0,2 моль; n(H) = 0,4 моль
3. m(C+H) = 2,8 г; m(O) = 2,6 г; n(O) = 0,1625 моль
4. Соотношение ≈ 4 : 8 : 3 — уточнение: C4H8O3?
5. Проверка: C4H8O2 (масляная кислота) — не реагирует с Na с H2? Нет, реагирует.
6. C4H8O (бутанол) — реагирует с Na, не реагирует с NaOH
7. Формула: C4H8O (бутанол-1 или бутанол-2)

**Задание 6.** При гидролизе 89 г жира получили 76,8 г стеариновой кислоты и глицерин. Определите выход реакции.

Ответ:
1. Тристеарин + 3H2O → 3C17H35COOH + C3H8O3
2. n(тристеарина) = 89 / 890 = 0,1 моль
3. n(теор., стеариновой кислоты) = 0,3 моль; m = 0,3 × 284 = 85,2 г
4. η = 76,8 / 85,2 × 100% = 90,1%

**Задание 7.** К 150 г 20%-ного раствора уксусной кислоты прибавили 50 г этанола. После реакции получили 44 г этилацетата. Определите выход реакции.

Ответ:
1. CH3COOH + C2H5OH → CH3COOC2H5 + H2O
2. m(CH3COOH) = 30 г; n = 0,5 моль
3. n(C2H5OH) = 50 / 46 = 1,087 моль — избыток
4. n(теор., этилацетата) = 0,5 моль; m(теор.) = 44 г
5. η = 44 / 44 × 100% = 100%

**Задание 8.** При сгорании 18,4 г органического вещества получили 17,92 л CO2 (н.у.) и 14,4 г H2O. Вещество реагирует с NaHCO3 с выделением газа. Определите формулу.

Ответ:
1. n(CO2) = 0,8 моль; n(C) = 0,8 моль; m(C) = 9,6 г
2. n(H2O) = 0,8 моль; n(H) = 1,6 моль; m(H) = 1,6 г
3. m(O) = 18,4 – 11,2 = 7,2 г; n(O) = 0,45 моль
4. C : H : O = 0,8 : 1,6 : 0,45 ≈ 16 : 32 : 9 — нецелое
5. Пересчёт: возможно, C4H8O2 (масляная кислота) — реагирует с NaHCO3
6. Проверка: M(C4H8O2) = 88 г/моль; n = 18,4 / 88 = 0,209 моль
7. При сгорании 1 моль C4H8O2 → 4 моль CO2: n(CO2) = 0,209 × 4 = 0,836 моль ≈ 0,8 моль ✓
8. Формула: C4H8O2 (масляная кислота)

**Задание 9.** Смесь бензола и толуола массой 20 г обработали избытком бромной воды. Образовался осадок массой 33,1 г. Определите массовую долю толуола в смеси.

Ответ:
1. C6H5CH3 + 3Br2 → C6H2Br3CH3↓ + 3HBr (бензол не реагирует с Br2-водой без катализатора)
2. n(осадка) = 33,1 / 331 = 0,1 моль = n(толуола)
3. m(толуола) = 0,1 × 92 = 9,2 г
4. ω(толуола) = 9,2 / 20 × 100% = 46%

**Задание 10.** При окислении 10 г глюкозы аммиачным раствором оксида серебра получили 8,64 г серебра. Определите выход реакции.

Ответ:
1. C6H12O6 + 2[Ag(NH3)2]OH → C6H12O7 + 2Ag + 4NH3 + H2O
2. n(глюкозы) = 10 / 180 = 0,0556 моль
3. n(теор., Ag) = 2 × 0,0556 = 0,111 моль; m(теор.) = 12 г
4. η = 8,64 / 12 × 100% = 72%

**Задание 11.** К 300 г 15%-ного раствора гидроксида калия прибавили 40 г кремниевой кислоты. Определите массовую долю силиката калия в растворе.

Ответ:
1. H2SiO3 + 2KOH → K2SiO3 + 2H2O
2. m(KOH) = 45 г; n(KOH) = 0,804 моль
3. n(H2SiO3) = 40 / 78 = 0,513 моль
4. Лимитирующий — H2SiO3 (нужно 2 KOH на 1 H2SiO3; у нас 0,804 / 2 = 0,402 < 0,513)
5. n(K2SiO3) = 0,402 моль; m = 0,402 × 154 = 61,9 г
6. m(раствора после) = 300 + 40 = 340 г
7. ω(K2SiO3) = 61,9 / 340 × 100% = 18,2%

**Задание 12.** При сгорании 13,8 г органического вещества получили 26,4 г CO2 и 16,2 г H2O. Вещество реагирует с натрием, но не реагирует с NaOH. Определите формулу.

Ответ:
1. n(CO2) = 0,6 моль; n(C) = 0,6 моль
2. n(H2O) = 0,9 моль; n(H) = 1,8 моль
3. m(C+H) = 7,2 + 1,8 = 9 г; m(O) = 4,8 г; n(O) = 0,3 моль
4. C : H : O = 0,6 : 1,8 : 0,3 = 2 : 6 : 1
5. Простейшая: C2H6O (M = 46 г/моль)
6. Проверка: 13,8 / 46 = 0,3 моль; при сгорании 0,3 моль → 0,6 моль CO2 ✓
7. Формула: C2H6O (этанол — реагирует с Na, не реагирует с NaOH)

**Задание 13.** При взаимодействии 22 г пропаналя с избытком аммиачного раствора оксида серебра получили 43,2 г серебра. Определите выход реакции.

Ответ:
1. C2H5CHO + [Ag(NH3)2]OH → C2H5COOH + 2Ag + 4NH3 + H2O
2. n(C2H5CHO) = 22 / 58 = 0,379 моль
3. n(теор., Ag) = 2 × 0,379 = 0,759 моль; m(теор.) = 82 г
4. η = 43,2 / 82 × 100% = 52,7%

**Задание 14.** К 250 г 12%-ного раствора карбоната натрия прибавили 200 г 10%-ного раствора хлорида кальция. Определите массу осадка.

Ответ:
1. Na2CO3 + CaCl2 → CaCO3↓ + 2NaCl
2. m(Na2CO3) = 30 г; n = 30 / 106 = 0,283 моль3. m(CaCl2) = 20 г; n = 20 / 111 = 0,180 моль
3. Лимитирующий — CaCl2
4. n(CaCO3) = 0,180 моль; m = 0,180 × 100 = 18 г

**Задание 15.** Смесь этана и этилена объёмом 20 л (н.у.) пропустили через избыток бромной воды. Объём газа после реакции составил 8 л (н.у.). Определите объёмные доли газов в исходной смеси.

Ответ:
1. C2H4 + Br2 → C2H4Br2 (этан не реагирует, остаётся в газовой фазе)
2. V(C2H6) = 8 л
3. V(C2H4) = 20 – 8 = 12 л
4. φ(C2H4) = 12 / 20 × 100% = 60%
5. φ(C2H6) = 8 / 20 × 100% = 40%
