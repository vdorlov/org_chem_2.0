# Блок 8. Задание 33 — Органическая расчётная задача

---

**Задание 1.** При пропускании 11,2 л (н.у.) этилена через избыток бромной воды получили 80,5 г бромэтана. Определите выход реакции.

Ответ:
1. C2H4 + Br2 → C2H4Br2
2. n(C2H4) = 11,2 / 22,4 = 0,5 моль
3. n(теор., C2H4Br2) = 0,5 моль
4. m(теор.) = 0,5 × 188 = 94 г
5. η = 80,5 / 94 × 100% = 85,6%

**Задание 2.** Смесь этилена и этана массой 10 г пропустили через избыток бромной воды. Масса брома, вступившего в реакцию, 32 г. Определите массовую долю этилена в смеси.

Ответ:
1. C2H4 + Br2 → C2H4Br2 (этан не реагирует)
2. n(Br2) = 32 / 160 = 0,2 моль
3. n(C2H4) = 0,2 моль
4. m(C2H4) = 0,2 × 28 = 5,6 г
5. ω(C2H4) = 5,6 / 10 × 100% = 56%

**Задание 3.** При сгорании 4,6 г органического вещества получили 8,8 г CO2 и 5,4 г H2O. Определите молекулярную формулу, если M = 46 г/моль.

Ответ:
1. n(CO2) = 0,2 моль; n(C) = 0,2 моль; m(C) = 2,4 г
2. n(H2O) = 0,3 моль; n(H) = 0,6 моль; m(H) = 0,6 г
3. m(O) = 4,6 – 2,4 – 0,6 = 1,6 г; n(O) = 0,1 моль
4. n(C) : n(H) : n(O) = 0,2 : 0,6 : 0,1 = 2 : 6 : 1
5. C2H6O (M = 46 г/моль)

**Задание 4.** При сгорании 17,55 г органического вещества получили 16,8 л CO2 (н.у.), 1,68 л N2 (н.у.) и 14,85 г H2O. При нагревании с водным раствором NaOH вещество гидролизуется, одним из продуктов является пропанол-1. Определите формулу.

Ответ:
1. n(CO2) = 0,75 моль; n(C) = 0,75 моль
2. n(H2O) = 0,825 моль; n(H) = 1,65 моль
3. n(N2) = 0,075 моль; n(N) = 0,15 моль
4. m(C+H+N) = 12,75 г; m(O) = 4,8 г; n(O) = 0,3 моль
5. n(C) : n(H) : n(N) : n(O) = 5 : 11 : 1 : 2
6. C5H11NO2 (пропиловый эфир аминоуксусной кислоты)

**Задание 5.** При взаимодействии 30 г уксусной кислоты с избытком этанола получили 35,2 г этилацетата. Определите выход реакции.

Ответ:
1. CH3COOH + C2H5OH → CH3COOC2H5 + H2O
2. n(CH3COOH) = 30 / 60 = 0,5 моль
3. n(теор.) = 0,5 моль
4. m(теор.) = 0,5 × 88 = 44 г
5. η = 35,2 / 44 × 100% = 80%

**Задание 6.** Смесь пропана и пропена массой 15 г обесцвечивает 80 г 20%-ной бромной воды. Определите массовую долю пропана в смеси.

Ответ:
1. C3H6 + Br2 → C3H6Br2
2. m(Br2) = 80 × 0,2 = 16 г; n(Br2) = 0,1 моль
3. n(C3H6) = 0,1 моль; m(C3H6) = 0,1 × 42 = 4,2 г
4. m(C3H8) = 15 – 4,2 = 10,8 г
5. ω(C3H8) = 10,8 / 15 × 100% = 72%

**Задание 7.** При сгорании 3,0 г органического вещества получили 3,36 л CO2 (н.у.) и 3,6 г H2O. Плотность паров вещества по водороду равна 30. Определите формулу.

Ответ:
1. n(CO2) = 0,15 моль; n(C) = 0,15 моль
2. n(H2O) = 0,2 моль; n(H) = 0,4 моль
3. m(C+H) = 1,8 + 0,4 = 2,2 г; m(O) = 0,8 г; n(O) = 0,05 моль
4. n(C) : n(H) : n(O) = 0,15 : 0,4 : 0,05 = 3 : 8 : 1
5. M(ист.) = 30 × 2 = 60 г/моль; M(C3H8O) = 60 г/моль
6. C3H8O (пропанол-1 или пропанол-2)

**Задание 8.** К 20 г этилена прибавили 80 г брома. Какая масса 1,2-дибромэтана образуется?

Ответ:
1. C2H4 + Br2 → C2H4Br2
2. n(C2H4) = 20 / 28 = 0,714 моль; n(Br2) = 80 / 160 = 0,5 моль
3. Лимитирующий — Br2
4. n(C2H4Br2) = 0,5 моль; m = 0,5 × 188 = 94 г

**Задание 9.** При гидролизе 34,2 г сахарозы получили 16,2 г глюкозы. Определите выход реакции.

Ответ:
1. C12H22O11 + H2O → C6H12O6 (глюкоза) + C6H12O6 (фруктоза)
2. n(C12H22O11) = 34,2 / 342 = 0,1 моль
3. n(теор., глюкозы) = 0,1 моль; m(теор.) = 0,1 × 180 = 18 г
4. η = 16,2 / 18 × 100% = 90%

**Задание 10.** При окислении 20 г этаналя аммиачным раствором оксида серебра получили 43,2 г серебра. Определите выход реакции.

Ответ:
1. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O
2. n(CH3CHO) = 20 / 44 = 0,455 моль
3. n(теор., Ag) = 2 × 0,455 = 0,91 моль
4. m(теор., Ag) = 0,91 × 108 = 98,3 г
5. η = 43,2 / 98,3 × 100% = 44%

**Задание 11.** Смесь ацетилена и этилена массой 8 г пропустили через избыток аммиачного раствора оксида серебра(I). Образовался осадок массой 24 г. Определите массовую долю ацетилена в смеси.

Ответ:
1. C2H2 + [Ag(NH3)2]OH → Ag2C2↓ (этилен не реагирует)
2. n(Ag2C2) = 24 / 240 = 0,1 моль = n(C2H2)
3. m(C2H2) = 0,1 × 26 = 2,6 г
4. ω(C2H2) = 2,6 / 8 × 100% = 32,5%

**Задание 12.** При сгорании 9,2 г органического вещества получили 17,6 г CO2 и 10,8 г H2O. Плотность паров по воздуху равна 1,586. Определите формулу.

Ответ:
1. n(CO2) = 0,4 моль; n(C) = 0,4 моль; m(C) = 4,8 г
2. n(H2O) = 0,6 моль; n(H) = 1,2 моль; m(H) = 1,2 г
3. m(O) = 9,2 – 4,8 – 1,2 = 3,2 г; n(O) = 0,2 моль
4. n(C) : n(H) : n(O) = 2 : 6 : 1
5. M(ист.) = 1,586 × 29 = 46 г/моль
6. C2H6O (этанол или диметиловый эфир)

**Задание 13.** При взаимодействии 14 г этилена с 40 г брома получили 37,6 г 1,2-дибромэтана. Определите выход реакции.

Ответ:
1. C2H4 + Br2 → C2H4Br2
2. n(C2H4) = 0,5 моль; n(Br2) = 0,25 моль; лимитирующий — Br2
3. n(теор., C2H4Br2) = 0,25 моль; m(теор.) = 0,25 × 188 = 47 г
4. η = 37,6 / 47 × 100% = 80%

**Задание 14.** К 200 г раствора бромоводородной кислоты с массовой долей 20% прибавили избыток этилена. Какова массовая доля бромэтана в полученном растворе?

Ответ:
1. C2H4 + HBr → C2H5Br
2. m(HBr) = 200 × 0,2 = 40 г; n(HBr) = 40 / 81 = 0,494 моль
3. n(C2H5Br) = 0,494 моль; m(C2H5Br) = 0,494 × 109 = 53,8 г
4. m(C2H4) = 0,494 × 28 = 13,8 г
5. m(раствора после) = 200 + 13,8 = 213,8 г
6. ω(C2H5Br) = 53,8 / 213,8 × 100% = 25,2%

**Задание 15.** При окислении 8 г метанола оксидом меди(II) получили 6,4 г метаналя. Определите выход реакции.

Ответ:
1. CH3OH + CuO → HCHO + Cu + H2O
2. n(CH3OH) = 8 / 32 = 0,25 моль
3. n(теор., HCHO) = 0,25 моль; m(теор.) = 0,25 × 30 = 7,5 г
4. η = 6,4 / 7,5 × 100% = 85,3%

**Задание 16.** При сгорании 10,5 г органического вещества получили 16,8 л CO2 (н.у.) и 13,5 г H2O. Определите формулу.

Ответ:
1. n(CO2) = 0,75 моль; n(C) = 0,75 моль; m(C) = 9 г
2. n(H2O) = 0,75 моль; n(H) = 1,5 моль; m(H) = 1,5 г
3. m(C+H) = 10,5 г = m(вещества) → кислорода нет
4. n(C) : n(H) = 0,75 : 1,5 = 1 : 2
5. Простейшая формула: CH2 (но это не может быть устойчивым веществом)
6. Уточнение: C6H12 (гексен или циклогексан)

**Задание 17.** Смесь метана и ацетилена объёмом 10 л (н.у.) пропустили через избыток аммиачного раствора оксида серебра(I). Образовался осадок массой 48 г. Определите объёмную долю ацетилена в смеси.

Ответ:
1. C2H2 + [Ag(NH3)2]OH → Ag2C2↓ (метан не реагирует)
2. n(Ag2C2) = 48 / 240 = 0,2 моль = n(C2H2)
3. V(C2H2) = 0,2 × 22,4 = 4,48 л
4. φ(C2H2) = 4,48 / 10 × 100% = 44,8%

**Задание 18.** При гидролизе 100 г жира (тристеарина) получили 92 г стеариновой кислоты. Определите выход реакции.

Ответ:
1. Тристеарин + 3H2O → 3C17H35COOH + глицерин
2. n(тристеарина) = 100 / 890 = 0,112 моль
3. n(теор., стеариновой кислоты) = 0,337 моль; m = 0,337 × 284 = 95,7 г
4. η = 92 / 95,7 × 100% = 96,1%

**Задание 19.** При взаимодействии 12 г уксусной кислоты с 12 г метанола получили 14,8 г метилацетата. Определите выход реакции.

Ответ:
1. CH3COOH + CH3OH → CH3COOCH3 + H2O
2. n(CH3COOH) = 0,2 моль; n(CH3OH) = 0,375 моль; лимитирующий — CH3COOH
3. n(теор., CH3COOCH3) = 0,2 моль; m(теор.) = 0,2 × 74 = 14,8 г
4. η = 14,8 / 14,8 × 100% = 100%

**Задание 20.** При сгорании 6,9 г органического вещества получили 13,2 г CO2 и 8,1 г H2O. Определите формулу, если M = 46 г/моль.

Ответ:
1. n(CO2) = 0,3 моль; n(C) = 0,3 моль; m(C) = 3,6 г
2. n(H2O) = 0,45 моль; n(H) = 0,9 моль; m(H) = 0,9 г
3. m(O) = 6,9 – 3,6 – 0,9 = 2,4 г; n(O) = 0,15 моль
4. n(C) : n(H) : n(O) = 2 : 6 : 1
5. M(ист.) = 46 г/моль → C2H6O
