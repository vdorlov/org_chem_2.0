# Блок 8. Задание 32 — Цепочки превращений органических веществ

---

**Задание 1.** Напишите уравнения реакций, с помощью которых можно осуществить следующие превращения:

CH4 → X1 → X2 → X3 → X4

где X1 — хлорметан, X2 — метанол, X3 — метаналь, X4 — муравьиная кислота.

Ответ:
1. CH4 + Cl2 → CH3Cl + HCl (hν)
2. CH3Cl + KOH(водн.) → CH3OH + KCl (t°)
3. CH3OH + CuO → HCHO + Cu + H2O (t°)
4. HCHO + [Ag(NH3)2]OH → HCOOH + 2Ag + 4NH3 + H2O

**Задание 2.** Напишите уравнения реакций:

C2H4 → X1 → X2 → X3

где X1 — этанол, X2 — этаналь, X3 — уксусная кислота.

Ответ:
1. CH2=CH2 + H2O → C2H5OH (H+, t°)
2. C2H5OH + CuO → CH3CHO + Cu + H2O (t°)
3. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O

**Задание 3.** Напишите уравнения реакций:

C2H2 → X1 → X2 → X3

где X1 — этаналь, X2 — этанол, X3 — этилен.

Ответ:
1. CH≡CH + H2O → CH3CHO (Hg2+, H+, t°)
2. CH3CHO + H2 → C2H5OH (Ni, t°)
3. C2H5OH → CH2=CH2 + H2O (H2SO4 конц., t° > 140 °C)

**Задание 4.** Напишите уравнения реакций:

C2H5OH → X1 → X2 → X3

где X1 — этилен, X2 — 1,2-дибромэтан, X3 — ацетилен.

Ответ:
1. C2H5OH → CH2=CH2 + H2O (H2SO4 конц., t° > 140 °C)
2. CH2=CH2 + Br2 → CH2Br–CH2Br
3. CH2Br–CH2Br + 2KOH(спирт.) → CH≡CH + 2KBr + 2H2O (t°)

**Задание 5.** Напишите уравнения реакций:

C6H5CH3 → X1 → X2 → X3

где X1 — бензойная кислота, X2 — бензоилхлорид, X3 — бензамид.

Ответ:
1. C6H5CH3 + KMnO4 + H2SO4 → C6H5COOH (t°)
2. C6H5COOH + PCl5 → C6H5COCl + POCl3 + HCl
3. C6H5COCl + NH3 → C6H5CONH2 + HCl

**Задание 6.** Напишите уравнения реакций:

CH3COOH → X1 → X2 → X3

где X1 — этилэтаноат, X2 — этанол, X3 — этаналь.

Ответ:
1. CH3COOH + C2H5OH → CH3COOC2H5 + H2O (H+, t°)
2. CH3COOC2H5 + NaOH → CH3COONa + C2H5OH (t°)
3. C2H5OH + CuO → CH3CHO + Cu + H2O (t°)

**Задание 7.** Напишите уравнения реакций:

CH3CHO → X1 → X2 → X3

где X1 — этанол, X2 — этилен, X3 — этан.

Ответ:
1. CH3CHO + H2 → C2H5OH (Ni, t°)
2. C2H5OH → CH2=CH2 + H2O (H2SO4 конц., t° > 140 °C)
3. CH2=CH2 + H2 → C2H6 (Ni, t°)

**Задание 8.** Напишите уравнения реакций:

CH3CH2Cl → X1 → X2 → X3

где X1 — этанол, X2 — этаналь, X3 — этанол.

Ответ:
1. CH3CH2Cl + KOH(водн.) → C2H5OH + KCl (t°)
2. C2H5OH + CuO → CH3CHO + Cu + H2O (t°)
3. CH3CHO + H2 → C2H5OH (Ni, t°)

**Задание 9.** Напишите уравнения реакций:

C6H6 → X1 → X2 → X3

где X1 — нитробензол, X2 — анилин, X3 — 2,4,6-триброманилин.

Ответ:
1. C6H6 + HNO3 → C6H5NO2 + H2O (H2SO4 конц., t°)
2. C6H5NO2 + 6[H] → C6H5NH2 + 2H2O (Fe, HCl)
3. C6H5NH2 + 3Br2 → C6H2Br3NH2 + 3HBr (водн. Br2)

**Задание 10.** Напишите уравнения реакций:

CH3Cl → X1 → X2 → X3

где X1 — метанол, X2 — метаналь, X3 — метилметаноат.

Ответ:
1. CH3Cl + KOH(водн.) → CH3OH + KCl (t°)
2. CH3OH + CuO → HCHO + Cu + H2O (t°)
3. HCHO + [Ag(NH3)2]OH → HCOOH + 2Ag + 4NH3 + H2O
4. HCOOH + CH3OH → HCOOCH3 + H2O (H+, t°)

**Задание 11.** Напишите уравнения реакций:

C2H5OH → X1 → X2 → X3

где X1 — этаналь, X2 — уксусная кислота, X3 — метилацетат.

Ответ:
1. C2H5OH + CuO → CH3CHO + Cu + H2O (t°)
2. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O
3. CH3COOH + CH3OH → CH3COOCH3 + H2O (H+, t°)

**Задание 12.** Напишите уравнения реакций:

CH4 → X1 → X2 → X3

где X1 — ацетилен, X2 — этаналь, X3 — этанол.

Ответ:
1. 2CH4 → C2H2 + 3H2 (t° = 1500 °C)
2. C2H2 + H2O → CH3CHO (Hg2+, H+, t°)
3. CH3CHO + H2 → C2H5OH (Ni, t°)

**Задание 13.** Напишите уравнения реакций:

CH2=CH2 → X1 → X2 → X3

где X1 — этанол, X2 — этаналь, X3 — уксусная кислота.

Ответ:
1. CH2=CH2 + H2O → C2H5OH (H+, t°)
2. C2H5OH + CuO → CH3CHO + Cu + H2O (t°)
3. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O

**Задание 14.** Напишите уравнения реакций:

CH3CH2OH → X1 → X2 → X3

где X1 — этилен, X2 — этан, X3 — хлорэтан.

Ответ:
1. C2H5OH → CH2=CH2 + H2O (H2SO4 конц., t° > 140 °C)
2. CH2=CH2 + H2 → C2H6 (Ni, t°)
3. C2H6 + Cl2 → C2H5Cl + HCl (hν)

**Задание 15.** Напишите уравнения реакций:

C6H5CH3 → X1 → X2 → X3

где X1 — бензойная кислота, X2 — бензоат натрия, X3 — бензол.

Ответ:
1. C6H5CH3 + KMnO4 + H2SO4 → C6H5COOH (t°)
2. C6H5COOH + NaOH → C6H5COONa + H2O
3. C6H5COONa + NaOH(тв.) → C6H6 + Na2CO3 (t°)

**Задание 16.** Напишите уравнения реакций:

CH3CHO → X1 → X2 → X3

где X1 — уксусная кислота, X2 — этилацетат, X3 — этанол.

Ответ:
1. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O
2. CH3COOH + C2H5OH → CH3COOC2H5 + H2O (H+, t°)
3. CH3COOC2H5 + NaOH → CH3COONa + C2H5OH (t°)

**Задание 17.** Напишите уравнения реакций:

C2H2 → X1 → X2 → X3

где X1 — этаналь, X2 — уксусная кислота, X3 — ацетат натрия.

Ответ:
1. C2H2 + H2O → CH3CHO (Hg2+, H+, t°)
2. CH3CHO + [Ag(NH3)2]OH → CH3COOH + 2Ag + 4NH3 + H2O
3. CH3COOH + NaOH → CH3COONa + H2O

**Задание 18.** Напишите уравнения реакций:

CH3CH2CH2OH → X1 → X2 → X3

где X1 — пропен, X2 — 2-бромпропан, X3 — пропанол-2.

Ответ:
1. CH3CH2CH2OH → CH3CH=CH2 + H2O (H2SO4 конц., t° > 140 °C)
2. CH3CH=CH2 + HBr → CH3CHBrCH3 (по Марковникову)
3. CH3CHBrCH3 + KOH(водн.) → CH3CHOHCH3 + KBr (t°)

**Задание 19.** Напишите уравнения реакций:

C6H5NO2 → X1 → X2 → X3

где X1 — анилин, X2 — хлорид фениламмония, X3 — анилин.

Ответ:
1. C6H5NO2 + 6[H] → C6H5NH2 + 2H2O (Fe, HCl)
2. C6H5NH2 + HCl → [C6H5NH3]Cl
3. [C6H5NH3]Cl + NaOH → C6H5NH2 + NaCl + H2O

**Задание 20.** Напишите уравнения реакций:

CH3OH → X1 → X2 → X3

где X1 — метаналь, X2 — муравьиная кислота, X3 — метилметаноат.

Ответ:

2. HCHO + [Ag(NH3)2]OH → HCOOH + 2Ag + 4NH3 + H2O

**Задание 21.** Напишите уравнения реакций:

**Задание 22.** Напишите уравнения реакций:

CH3COOC2H5 → X1 → X2 → X3

**Задание 23.** Напишите уравнения реакций:

C2H5OH → X1 → X2 → X3

**Задание 24.** Напишите уравнения реакций:

CH4 → X1 → X2 → X3

**Задание 25.** Напишите уравнения реакций:

**Задание 26.** Напишите уравнения реакций:

**Задание 27.** Напишите уравнения реакций:

CH3CH2OH → X1 → X2 → X3

3. CH2Cl–CH2Cl + 2KOH(водн.) → HOCH2–CH2OH + 2KCl (t°)

**Задание 28.** Напишите уравнения реакций:

CH3CHO → X1 → X2 → X3

**Задание 30.** Напишите уравнения реакций:
