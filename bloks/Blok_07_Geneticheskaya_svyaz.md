# Блок 7. Генетическая связь между классами органических веществ

---

## 7.1. Что такое генетическая связь?

Генетическая связь — это последовательность химических превращений, в которых одни органические соединения переходят в другие. Слово «генетический» здесь означает «относящийся к происхождению» (от греч. genesis — происхождение), а не связанный с генами.

### Почему генетическая связь — ключ к пониманию органической химии?

Органическая химия — это не набор изолированных фактов, а система взаимосвязей. Каждый класс соединений может быть получен из другого класса и может быть превращён в другой класс. Понимание этих связей позволяет:

1. **Предсказывать продукты реакций**, даже если вы их раньше не встречали
2. **Составлять цепочки превращений** (задание 32 ЕГЭ)
3. **Понимать логику органического синтеза** — как из простых веществ получить сложные
4. **Не заучивать**, а **понимать** — потому что каждый переход имеет логическое объяснение

### Основная идея генетической связи

В основе всех превращений лежит изменение функциональной группы или углеводородного скелета:

- **Замещение** — одна группа заменяется на другую (–Hal → –OH, –OH → –NH2)
- **Присоединение** — к кратной связи присоединяются атомы (C=C + H2O → спирт)
- **Элиминирование** — отщепляются атомы с образованием кратной связи (спирт → алкен + H2O)
- **Окисление** — добавление кислорода / удаление водорода (спирт → альдегид → кислота)
- **Восстановление** — добавление водорода / удаление кислорода (альдегид → спирт)
- **Гидролиз** — расщепление связи водой (эфир → кислота + спирт, амид → кислота + амин)

## 7.2. Логика основной генетической цепочки

### Центральная схема органического синтеза

```
Углеводород → Галогенпроизводное → Спирт → Альдегид/Кетон → Кислота → Сложный эфир/Жир/Амид
```

Почему именно такая последовательность? Потому что каждый следующий шаг — это логическое продолжение предыдущего:

**Шаг 1: Углеводород → Галогенпроизводное**
Почему начинаем с галогена? Потому что C–Hal связь полярная, и галоген — хорошая уходящая группа. Это делает галогенопроизводное универсальным «перекрёстком», откуда можно пойти в любой класс.

**Шаг 2: Галогенопроизводное → Спирт**
Гидролиз C–Hal → C–OH. OH-группа более реакционноспособна, чем галоген, и открывает путь к кислородсодержащим классам.

**Шаг 3: Спирт → Альдегид/Кетон**
Окисление спирта. Первичный спирт → альдегид (мягкое) → кислота (сильное). Вторичный спирт → кетон.

**Шаг 4: Альдегид → Кислота**
Дальнейшее окисление. Альдегидная группа –CHO очень чувствительна к окислителям.

**Шаг 5: Кислота → Сложный эфир / Жир / Амид**
Замещение OH-группы в –COOH на –OR (эфир), –NH2 (амид) или реакция с глицерином (жир).

### Сводная таблица типовых переходов

| Из класса | В класс | Реагент | Пример |
|-----------|---------|---------|--------|
| Алкан | Галогеналкан | Cl2, hν | CH4 → CH3Cl |
| Галогеналкан | Спирт | KOH (водн.) | CH3Cl → CH3OH |
| Спирт | Альдегид | CuO, t° | CH3OH → HCHO |
| Альдегид | Кислота | [Ag(NH3)2]OH | HCHO → HCOOH |
| Кислота | Сложный эфир | R'OH, H+, t° | CH3COOH → CH3COOCH3 |
| Алкен | Спирт | H2O, H+ | CH2=CH2 → C2H5OH |
| Алкин | Альдегид/Кетон | H2O, Hg2+, H+ | C2H2 → CH3CHO |
| Арен | Кислота | KMnO4, H+, t° | C6H5CH3 → C6H5COOH |
| Нитросоединение | Амин | Fe, HCl | C6H5NO2 → C6H5NH2 |
| Амид | Амин | Br2, NaOH | CH3CONH2 → CH3NH2 |

## 7.3. Подробный разбор типовых цепочек

### Цепочка 1: Алкан → Спирт → Альдегид → Кислота → Сложный эфир

**Полная цепочка:**

```
CH4 --[Cl2, hν]→ CH3Cl --[KOH(водн.), t°]→ CH3OH --[CuO, t°]→ HCHO
  --[[Ag(NH3)2]OH]→ HCOOH --[CH3OH, H+, t°]→ HCOOCH3
```

**Почему именно такие реагенты?**

1. **CH4 → CH3Cl**: Радикальное замещение. Свет (hν) вызывает гомолитический разрыв Cl–Cl с образованием атомарных радикалов Cl•, которые атакуют CH4. Почему не Br2? Br2 реагирует медленнее и селективнее. Cl2 даёт смесь продуктов, но для простых алканов это приемлемо.

2. **CH3Cl → CH3OH**: Нуклеофильное замещение SN2. KOH в водном растворе — источник нуклеофила OH−. Почему водный, а не спиртовой? Потому что нужно замещение (гидролиз), а не элиминирование.

3. **CH3OH → HCHO**: Окисление первичного спирта до альдегида. CuO при нагревании — мягкий окислитель. Почему не KMnO4? Потому что KMnO4 окислил бы сразу до кислоты.

4. **HCHO → HCOOH**: Окисление альдегида. [Ag(NH3)2]OH — мягкий окислитель, специфичный для альдегидов. Ag+ восстанавливается до Ag0 (серебряное зеркало).

5. **HCOOH → HCOOCH3**: Этерификация. Карбоновая кислота реагирует со спиртом в присутствии кислотного катализатора (H+), образуя сложный эфир и воду. Реакция обратима.

**Ключевой момент**: Каждый шаг — это изменение функциональной группы на «следующую ступень» в окислительно-восстановительной шкале: CH3– (алкан) → CH2Cl– (галоген) → CH2OH– (спирт) → CHO– (альдегид) → COOH– (кислота) → COOCH3– (эфир).

### Цепочка 2: Алкен → Галогенпроизводное → Алкин → Альдегид → Спирт

**Полная цепочка:**

```
CH2=CH2 --[Br2]→ CH2Br–CH2Br --[2KOH(спирт.), t°]→ CH≡CH
  --[H2O, Hg2+, H+, t°]→ CH3CHO --[H2, Ni]→ C2H5OH
```

**Почему именно такие реагенты?**

1. **CH2=CH2 → CH2Br–CH2Br**: Электрофильное присоединение Br2 к C=C. π-Электроны атакуют Br2, поляризуя его. Образуется циклический бромониевый ион (промежуточный), который затем атакуется Br− с обратной стороны — результат: транс-дибромид.

2. **CH2Br–CH2Br → CH≡CH**: Двойное элиминирование (дегидрогалогенирование). Два эквивалента KOH в спиртовом растворе при t° последовательно отщепляют две молекулы HBr. Первое элиминирование даёт бромэтен (CH2=CHBr), второе — ацетилен. Почему спиртовой KOH? Потому что нужно элиминирование, а не замещение.

3. **CH≡CH → CH3CHO**: Гидратация алкина по Кучерову. Вода присоединяется к тройной связи в присутствии Hg2+ (катализатор) и H+. В этине оба атома углерода эквивалентны, поэтому правило Марковникова не играет роли. Первый продукт — еноль CH2=CHOH, который тут же таутомеризуется в ацетальдегид CH3CHO. Это **кето-енольная таутомерия**.

4. **CH3CHO → C2H5OH**: Восстановление альдегида. H2 в присутствии Ni (или Pt, Pd) присоединяется к C=O, превращая альдегид в первичный спирт.

**Ключевой момент**: Эта цепочка демонстрирует переход от непредельного углеводорода (алкен) к ещё более непредельному (алкин) и затем к кислородсодержащим соединениям. Гидратация алкина — важнейший способ получения альдегидов и кетонов с заданным числом атомов углерода.

### Цепочка 3: Арен → Кислота → Галогенангидрид → Амид → Амин

**Полная цепочка:**

```
C6H5CH3 --[KMnO4, H+, t°]→ C6H5COOH --[PCl5]→ C6H5COCl
  --[NH3]→ C6H5CONH2 --[Br2, NaOH]→ C6H5NH2
```

**Почему именно такие реагенты?**

1. **Толуол → Бензойная кислота**: Окисление боковой цепи. KMnO4 в кислой среде при t° окисляет алкильную боковую цепь бензола до карбоксильной группы, если на α-углероде (соседнем с кольцом) есть хотя бы один атом водорода. Окисление идёт до бензойной кислоты (C6H5COOH) независимо от длины боковой цепи. Почему кольцо не окисляется? Потому что ароматическая система очень устойчива.

2. **Бензойная кислота → Бензоилхлорид**: Замещение OH в –COOH на Cl. PCl5 — сильный хлорирующий агент. Можно также использовать SOCl2 (тионилхлорид), который даёт более чистый продукт (побочные продукты SO2 и HCl — газы).

3. **Бензоилхлорид → Бензамид**: Присоединение аммиака. NH3 атакует электрофильный карбонильный углерод, Cl− уходит как уходящая группа.

4. **Бензамид → Анилин**: Реакция Гофмана (расщепление амидов по Гофману). Br2 в щелочной среде превращает амид в амин с потерей одного атома углерода (карбонильного). Механизм включает образование N-бромамида, перегруппировку в изоцианат (C6H5–N=C=O), гидролиз изоцианата до амина. **Важно**: цепь уменьшается на 1 C!

**Ключевой момент**: Эта цепочка показывает, как из ароматического углеводорода получить ароматический амин, проходя через все стадии функциональных групп. Реакция Гофмана — единственный способ в этой цепочке уменьшить число атомов углерода.

### Цепочка 4: Жир → Мыло → Кислота → Сложный эфир → Амин (через амид)

**Полная цепочка:**

```
Жир --[NaOH, t°]→ C17H35COONa --[HCl]→ C17H35COOH
  --[C2H5OH, H+, t°]→ C17H35COOC2H5 --[NH3]→ C17H35CONH2
  --[Br2, NaOH]→ C17H35NH2
```

**Почему именно такие реагенты?**

1. **Жир → Мыло (соль)**: Омыление — щелочной гидролиз жира. NaOH расщепляет эфирные связи между глицерином и жирными кислотами, образуя соли (мыло) и глицерин. Это необратимый процесс, потому что образующаяся кислота тут же нейтрализуется щёлочью.

2. **Мыло → Стеариновая кислота**: Действие сильной кислоты (HCl) на соль мыла. Катион H+ протонирует карбоксилат-анион, выделяя свободную карбоновую кислоту.

3. **Кислота → Этилстеарат**: Этерификация. Карбоновая кислота + спирт → сложный эфир + вода.

4. **Этилстеарат → Стеарамид**: Аммонолиз сложного эфира. NH3 замещает OC2H5-группу на NH2.

5. **Стеарамид → Октадециламин**: Реакция Гофмана. Амид → амин с уменьшением цепи на 1 C.

**Ключевой момент**: Эта цепочка показывает взаимосвязь жиров с другими классами органических соединений. Жиры — не изолированный класс, а часть общей системы.

## 7.4. Типичные «ловушки» в цепочках превращений

### Ловушка 1: Изменение числа атомов углерода

В ЕГЭ часто дают цепочки, где число атомов углерода меняется. Это проверяет внимательность и понимание реакций.

**Реакции, увеличивающие цепь:**
- Реакция Вюрца: 2 CH3Cl + 2 Na → C2H6 (удвоение)
- Действие KCN: CH3Cl + KCN → CH3CN → CH3COOH (+1 C)
- Реактив Гриньяра + CO2: C2H5MgBr + CO2 → C3H7COOH (+1 C)

**Почему KCN удлиняет цепь?** Потому что CN− — нуклеофил, который замещает галоген. Затем нитрил гидролизуется до кислоты. Итого: R–Hal → R–CN → R–COOH. Цепь стала длиннее на 1 C (добавился карбонильный C).

**Реакции, уменьшающие цепь:**
- Реакция Гофмана: R–CONH2 → R–NH2 (–1 C)
- Декарбоксилирование: R–COOH → R–H + CO2 (–1 C)

**Реакции, расщепляющие цепь:**
- Резкое окисление алкенов KMnO4 (H+, t°): R–CH=CH–R' → R–COOH + R'–COOH
- Резкое окисление кетонов: R–CO–R' → R–COOH + R'–COOH
- Крекинг: C8H18 → C4H10 + C4H8

**Почему KMnO4 расщепляет алкен?** При резком окислении двойная связь разрывается полностью. Каждый атом углерода двойной связи окисляется до карбоксильной группы (или до CO2, если при C=C был H). Это позволяет определить положение двойной связи в молекуле.

### Ловушка 2: Перегруппировки

**Кето-енольная таутомерия:**

При гидратации алкинов первоначально образуется еноль (соединение с C=C и –OH на одном C):

```
CH≡CH + H2O → [CH2=CH–OH] (еноль) → CH3–CHO (альдегид)
```

Еноли неустойчивы, потому что карбонильная форма (альдегид/кетон) энергетически выгоднее. Перегруппировка идёт через миграцию протона и перестройку π-системы.

**Перегруппировка карбокатионов:**

При некоторых реакциях (например, при дегидратации спиртов в кислой среде) образующийся карбокатион может перегруппировываться — H или CH3-группа переносится с соседнего атома углерода, образуя более стабильный карбокатион. Это приводит к продуктам, которые кажутся «неожиданными».

**Пример:** Дегидратация 2,2-диметилпропанол-1 в кислой среде даёт не ожидаемый 2,2-диметилпропен, а 2-метилбутен-2 (более замещённый, более стабильный алкен) через перегруппировку Вагнера-Меервейна.

### Ловушка 3: Условия реакции

Одна и та же реагентная пара может давать разные продукты в зависимости от условий:

**Дегидратация спирта:**
- H2SO4(конц.), t° = 170 °C → алкен (внутримолекулярное элиминирование)
- H2SO4(конц.), t° = 140 °C → простой эфир (межмолекулярное замещение)

**Почему разница?** При 170 °C преобладает элиминирование (E1/E2), потому что энергия активации выше, но энтропия выгоднее (образуется больше молекул). При 140 °C преобладает замещение (SN2), потому что энергии достаточно для замещения, но не для элиминирования. Кроме того, при 140 °C избыток спирта способствует SN2 (спирт — и субстрат, и нуклеофил).

**KOH водный vs спиртовой:**
- KOH(водн.), t° → замещение (гидролиз → спирт)
- KOH(спирт.), t° → элиминирование (отщепление → алкен)

**Почему разница?** Водный раствор KOH — хороший источник нуклеофила OH−, который атакует C–Hal с замещением. Спиртовой раствор KOH — более сильное основание (спирт менее полярен, чем вода, поэтому OH− менее сольватирован и более реакционноспособен как основание), которое отщепляет HHal с образованием алкена.

**Галогенирование толуола:**
- Cl2, FeCl3 (кат.) → замещение в кольце (ионное электрофильное)
- Cl2, hν (свет) → замещение в боковой цепи (радикальное)

**Почему разница?** FeCl3 — катализатор Льюиса, который поляризует Cl2, создавая электрофил Cl+. Этот электрофил атакует π-систему бензольного кольца. Свет (hν) вызывает гомолитический разрыв Cl–Cl с образованием радикалов Cl•, которые атакуют C–H связи боковой цепи (как в алканах).

### Ловушка 4: Промежуточные продукты

Некоторые реакции идут через промежуточные соединения, которые не указываются в цепочке, но нужно понимать, что они существуют:

**Гидратация алкина:**
```
CH≡CH + H2O → [CH2=CH–OH] (еноль, промежуточный) → CH3–CHO (альдегид, конечный)
```

**Гидролиз нитрила:**
```
R–CN + H2O → [R–CONH2] (амид, промежуточный) → R–COOH (кислота, конечный)
```

**Окисление 1° спирта:**
```
R–CH2OH + [O] → [R–CHO] (альдегид, промежуточный при мягком окислении) → R–COOH (кислота, при сильном)
```

**Почему это важно?** Потому что в задании 32 нужно указывать преимущественно образующиеся продукты. Если в условии сказано «окислить до кислоты», то промежуточный альдегид не указывается. Но если сказано «окислить мягко до альдегида», то указывается альдегид.

## 7.5. Алгоритм решения задания 32

### Шаг 1: Определить исходное и конечное вещества

Записать формулы или структурные формулы начального и конечного веществ. Определить их классы.

**Пример:**
- Начальное: CH3CH2Cl (хлорэтан, галогенопроизводное)
- Конечное: CH3COOCH2CH3 (этилэтаноат, сложный эфир)

### Шаг 2: Определить направление превращения

Какой класс в какой превращается? Какое число атомов C? Изменяется ли оно?

**Пример:**
- Хлорэтан (2 C) → Этилэтаноат (4 C). Цепь удвоилась! Значит, где-то была реакция Вюрца или присоединение через нитрил.

### Шаг 3: Подобрать маршрут

Использовать таблицу генетической связи. Искать путь от начального к конечному веществу.

**Пример:**
```
CH3CH2Cl → ? → CH3COOCH2CH3
```

Возможный путь:
1. CH3CH2Cl + KCN → CH3CH2CN (нитрил, +1 C)
2. CH3CH2CN + H2O (H+, t°) → CH3CH2COOH (пропановая кислота, 3 C)
3. CH3CH2COOH + C2H5OH (H+, t°) → CH3CH2COOC2H5 (этилпропаноат, 5 C) — не то!

Другой путь:
1. 2 CH3CH2Cl + 2 Na → CH3CH2–CH2CH3 (бутан, реакция Вюрца, 4 C)
2. CH3CH2CH2CH3 + [O] → ? — ложно

Третий путь:
1. CH3CH2Cl + KOH(водн.) → CH3CH2OH (этанол)
2. CH3CH2OH + [O] → CH3CHO (ацетальдегид)
3. CH3CHO + [O] → CH3COOH (уксусная кислота)
4. CH3COOH + CH3CH2OH → CH3COOCH2CH3 (этилэтаноат) — совпадает!

## Типичные ошибки ЕГЭ (задание 32)

| Ошибка | Почему ошибка | Правильно |
|--------|--------------|-----------|
| Запись молекулярных формул вместо структурных | Не понимается требование задания | Всегда писать структурные формулы |
| Пропуск коэффициентов в уравнениях | Невнимательность или неумение уравнивать | Проверять баланс атомов и зарядов |
| Неправильные условия реакций | Зубрёжка без понимания | Понимать, почему нужна именно эта t°/катализатор |
| Смешение KOH водного и спиртового растворов | Не понимается механизм | Водный → замещение (SN); спиртовой → элиминирование (E) |
| Неучёт изменения числа C в цепи | Невнимательность | Проверять каждый переход |
| Забывание о таутомерии при гидратации алкинов | Не понимается промежуточный продукт | Еноль → карбонильное соединение (альдегид/кетон) |
| Путаница в окислении спиртов | Не понимается стадийность | 1° спирт → альдегид (мягко) → кислота (сильно); 2° → кетон |
| Неправильное применение реакции Гофмана | Не понимается уменьшение цепи | Только для амидов; уменьшает цепь на 1 C |
| Указание FeCl3 при галогенировании алканов | Смешение условий | FeCl3 — для аренов; hν или t° — для алканов |
| Указание hν при галогенировании бензола | Смешение механизмов | hν → радикальное (для боковой цепи толуола); FeCl3 → ионное (для кольца) |
