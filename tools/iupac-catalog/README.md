# Справочник ИЮПАК

Интерактивный справочник органических соединений с 3D-визуализацией.

## Как работает

1. Пользователь выбирает соединение из списка.
2. Сайт запрашивает SMILES из PubChem PUG REST API.
3. 3Dmol.js рендерит интерактивную 3D-модель молекулы.

## Лицензии и правовая информация

- **3Dmol.js** — BSD License (свободное использование, включая коммерческие проекты).
- **PubChem PUG REST API** — публичный API NIH, разрешён для образовательных целей.
  - Ограничение: не более 5 запросов в секунду[citation:3].
  - При превышении — временная блокировка IP.
- **Данные о молекулах** — Public Domain (NIH).

## Ограничения

- PubChem может вернуть 404 для редких названий. В таком случае можно использовать альтернативу — SMILES-строку, заданную вручную в каталоге.
- При частых кликах возможен rate-limit (503). Кэш в `smilesCache` снижает количество запросов.

## Расширение каталога

Добавьте новое соединение в объект `CATALOG` в `iupac-catalog.js`:

```js
{
  name: 'Название',
  iupac: 'iupac-name-for-pubchem',
  formula: 'Формула'
}
