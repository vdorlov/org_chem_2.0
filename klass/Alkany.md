# Алканы

#углеводороды_органика

Алканы также называют **парафинами** («мало сродства»), так как это предельные углеводороды, поэтому реагируют с небольшим количеством соединений, чаще всего в конкретных условиях.

**Общая формула:** CₙH₂ₙ₊₂

**Примеры:** CH₄ (метан), C₂H₆ (этан), C₃H₈ (пропан), C₄H₁₀ (бутан), C₅H₁₂ (пентан), C₆H₁₄ (гексан), C₇H₁₆ (гептан)

---

**Изомерия алканов**

| Вид изомерии | Описание | Примеры |
|--------------|----------|---------|
| **Изомерия углеродного скелета** | Различный порядок соединения атомов углерода (разветвлённая или линейная цепь). Начиная с C₄H₁₀. | C₄H₁₀:<br>1. **н-бутан** (CH₃–CH₂–CH₂–CH₃)<br>2. **изобутан** (2-метилпропан) (CH₃–CH(CH₃)–CH₃) |

---

**Реакции и взаимодействия:**

- **Замещение Cl₂, Br₂ (чистые)**
	  - CH₃–CH₂–CH₂–CH₃ + Cl₂ → (условие: свет hν) CH₃–CH(Cl)–CH₂–CH₃ + HCl
	  - CH₃–CH₂–CH₂–CH₃ + Br₂ → (условие: свет hν) CH₃–CH(Br)–CH₂–CH₃ + HBr (бром идёт в середину ближе к началу)

- **Окисление O₂**
	  - CₙH₂ₙ₊₂ + O₂ → CO₂ + H₂O

- **HNO₃ (реакция Коновалова)**
	  - CH₃–CH₃ + HO–NO₂ (разбавленная HNO₃) → H–OH + CH₃–CH₂NO₂ (нитроэтан)

- **Крекинг (термический и каталитический)**
	  - C₈H₁₈ → C₄H₈ + C₄H₁₀ (термическая реакция)
	  - 2CH₃–CH₂–CH₂–CH₃ + 5O₂ (кислород выступает как катализатор) → 4CH₃–COOH + 2H₂O

- **Изомеризация**
	  - CH₃–CH₂–CH₂–CH₃ → (условия: температура 100 °C и AlCl₃) CH₃–CH(**CH₃**)–CH₃ (2-метилпропан)

- **Дегидрирование**
	  - C₂H₆ → (условие: Cr₂O₆) C₂H₄ + H₂ (образование алкена)

**Нет реакции:**
	- Br₂ (вода)
	- KMnO₄
	- H₂
	- HCl, HBr

---

**Получение алканов**

- **Гидролиз, реакция обмена**
	  - Al₄C₃ (карбид алюминия) + 12H–OH → 4Al(OH)₃ + 3CH₄

- **Реакция Вюрца** (применение металлического натрия на галогеналканы (–Cl, –Br), по итогу с увеличением длины алкана)
	  - 2CH₃Cl + 2Na → 2NaCl + C₂H₆
	  - 2C₃H₇Cl + 2Na → 2NaCl + C₆H₁₄
	  - 2C₃H₇Br (CH₃–CH(Br)–CH₃) + 2Na → 2NaBr + C₆H₁₄ (CH₃–CH(CH₃)–CH(CH₃)–CH₃) — 2,3-диметилбутан
	  - 2C₄H₉Br (CH₃–CH₂–CH(Br)–CH₃) + 2Na → 2NaBr + C₈H₁₈ (CH₃–CH₂–CH(CH₃)–CH(CH₃)–CH₂–CH₃) — 3,4-диметилгексан

- **Декарбоксилирование («откусывание головы»)**
	  - CH₃COONa (ацетат натрия) + NaOH → Na₂CO₃ + CH₄
	  - C₂H₅COONa + NaOH → Na₂CO₃ + C₂H₆
	  - C₄H₇COONa + NaOH → Na₂CO₃ + C₄H₁₀

- **Гидрирование**
	  - C₂H₄ + H₂ → (условие: 1500 °C и Ni) C₂H₆
	  - C₂H₂ + 2H₂ → (условие: 1500 °C и Ni) C₂H₆

**Важно запомнить (ПРОМЫШЛЕННОЕ ПОЛУЧЕНИЕ АЦЕТИЛЕНА):**
	- Крекинг метана: 2CH₄ → (условие: 1500 °C) C₂H₂ (ацетилен) + 3H₂

**Промышленное получение алканов:**
CH₄ выделяется из природного, попутного нефтяного газов и продуктов нефтепереработки.

**Последовательности реакций для закрепления**

- [ ] C₂H₆ → C₂H₅Cl → C₄H₁₀ → C₄H₁₀ (изомер) → CO₂
- [ ] CH₄ → C₂H₂ → C₂H₄ → C₂H₆ → C₂H₅Cl → C₄H₁₀ → CH₃COOH → CH₄
- [ ] CH₄ → CH₃Cl → C₂H₆ → C₂H₄ → C₂H₆ → C₂H₅Cl → C₄H₁₀ → CH₃COOH
- [ ] CH₃COONa → CH₄ → C₂H₂ → C₂H₆ → C₂H₅Cl → C₄H₁₀ → C₄H₉Br
- [ ] C₃H₈ → C₃H₇Cl → C₆H₁₄ → C₆H₆
- [ ] C₅H₁₂ → C₃H₈ → C₃H₇Br → C₆H₁₄ → C₆H₁₄ (изомер)
- [ ] CH₃COONa → CH₄ → C₂H₂ → C₂H₆ → C₂H₅Cl → C₂H₄Cl₂
