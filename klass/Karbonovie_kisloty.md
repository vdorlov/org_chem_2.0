# Карбоновые кислоты

#кислородосодержащая_органика

Карбоновые кислоты — производные углеводородов, молекулы которых содержат одну или несколько карбоксильных групп –COOH.

---

**Общая формула:**
- CₙH₂ₙO₂
- CₙH₂ₙ₊₁COOH

---

Карбоновые (органические) кислоты обладают всеми свойствами обычных (неорганических) кислот.

**ВАЖНО!** Правильные названия групп в «хвостике» –COOH:
- –C(=O)OH:
  - C=O — карбонильная группа
  - C–OH — карбоксильная группа

---

**Карбоновые кислоты** изомерны **сложным эфирам:**
- C₂H₅COOH — общая формула (C₃H₆O₂)
- CH₃COOC₂H₅ — общая формула (C₄H₈O₂)

Кислоты в зависимости от радикала могут быть:
- Ароматическими (образованными от бензола C₆H₅–COOH),
- Предельными (наши основные кислоты HCOOH, CH₃COOH и т.д.).

---

**Гомологический ряд карбоновых кислот:**

| Формула | Название | Где встречается |
|---|---|---|
| HCOOH | метановая кислота (муравьиная) | содержится в яде муравьёв и крапивы (вызывает жжение) |
| CH₃COOH | этановая кислота (уксусная) | содержится в столовом уксусе |
| C₂H₅COOH | пропановая кислота (пропионовая) | может содержаться в сырах и маслах |
| C₃H₇COOH | бутановая кислота (масляная) | содержится в сливочном масле |
| C₄H₉COOH | пентановая кислота (валериановая) | содержится в корне валерианы |

**Изомерия кислот:**

| Вид изомерии | Описание | Пример |
|---|---|---|
| **Структурная** |  |  |
| **1. Изомерия углеродного скелета** | Меняется строение углеводородного радикала (R), связанного с карбоксильной группой (–COOH). Сама группа –COOH всегда находится на конце цепи, поэтому **изомерия положения для неё невозможна**. Начинается с C₄. | **Бутановая (масляная) кислота** (CH₃–CH₂–CH₂–COOH) и **2-метилпропановая (изомасляная) кислота** ((CH₃)₂CH–COOH) |
| **2. Межклассовая изомерия** | Карбоновые кислоты изомерны сложным эфирам, а также некоторым гидроксикарбонильным соединениям (для непредельных). Общая формула предельных одноосновных кислот и сложных эфиров: CₙH₂ₙO₂. | **Уксусная кислота** (CH₃–COOH, C₂H₄O₂) и **метилформиат** (HCOO–CH₃, C₂H₄O₂) — сложный эфир.<br><br>**Пропановая кислота** (C₂H₅–COOH, C₃H₆O₂) и **метилацетат** (CH₃COO–CH₃, C₃H₆O₂) |
| **3. Изомерия положения заместителя** (для галоген-, гидрокси-, аминокислот) | Если в радикале есть другие функциональные группы (OH, NH₂, Hal), они могут находиться в разных положениях углеродной цепи (α, β, γ и т.д.). | **2-гидроксипропановая (молочная) кислота** (CH₃–CH(OH)–COOH) и **3-гидроксипропановая кислота** (HO–CH₂–CH₂–COOH) |
| **4. Изомерия положения кратной связи** (для непредельных кислот) | Если в углеводородном радикале есть двойная связь, она может находиться в разных положениях относительно карбоксильной группы. | **Бутен-2-овая (кротоновая) кислота** (CH₃–CH=CH–COOH) и **бутен-3-овая (винилуксусная) кислота** (CH₂=CH–CH₂–COOH) |
| **Пространственная (стереоизомерия)** |  |  |
| **5. Геометрическая (цис-транс-) изомерия** | Характерна для непредельных кислот, имеющих разные заместители при атомах углерода с двойной связью. | **Цис-бутен-2-овая (малеиновая) кислота** и **транс-бутен-2-овая (фумаровая) кислота** (резко отличаются по свойствам) |
| **6. Оптическая изомерия** | Возникает, если в молекуле есть асимметрический атом углерода (хиральный центр, связанный с 4 разными заместителями). | **2-гидроксипропановая (молочная) кислота** (CH₃–CH(OH)–COOH) — второй атом углерода является хиральным, существует в виде двух зеркальных изомеров (D- и L-молочная кислота) |

**Реакции и взаимодействия:**

- **Взаимодействие с щелочными металлами:**
	  - CH₃COOH + Na → CH₃COONa (ацетат натрия) + H₂
	  - HCOOH + Na → HCOONa (формиат натрия) + H₂
	  - C₂H₅COOH + K → C₂H₅COOK (пропионат калия) + H₂

- **Взаимодействие с основными оксидами:**
	  - CH₃COOH + CaO → (CH₃COO)₂Ca (ацетат кальция) + H₂O

- **Взаимодействие со щелочами:**
	  - C₂H₅COOH + NaOH → C₂H₅COONa (пропионат натрия) + H₂O

- **Взаимодействие с Cu(OH)₂:**
	  - CH₃COOH + Cu(OH)₂ → (CH₃COO)₂Cu (ацетат меди) + H₂O

- **Взаимодействие с солями более слабых кислот:**
	  - CH₃COOH + Na₂CO₃ → CH₃COONa + CO₂ + H₂O

- **Реакция этерификации (со спиртами):**
	  - C₂H₅COOH + CH₃OH → C₂H₅COOCH₃ (метилпропионат / метиловый эфир пропионовой кислоты) + H₂O
	  - CH₃COOH + C₂H₅OH → CH₃COOC₂H₅ (этилэтаноат / этилацетат / этиловый эфир этановой (уксусной) кислоты) + H₂O
	  - C₃H₇COOH + C₂H₅OH → C₃H₇COOC₂H₅ (этилбутират / этиловый эфир бутановой кислоты) + H₂O

- **Взаимодействие с аммиаком:**
	  - CH₃COOH + NH₃ → CH₃COONH₄ (ацетат аммония)
	  - CH₃COONH₄ → (t) CH₃C(=O)NH₂ (амид уксусной кислоты — переход в другой класс) + H₂O

- **Галогенирование (по основному радикалу):**
	  - CH₃–CH₂–COOH + Cl₂ → (красный фосфор и t) CH₃–CH(Cl)–COOH (хлорпропионовая кислота) + HCl
	  - CH₃COOH + Cl₂ → (красный фосфор и t) CH₂(Cl)COOH (хлоруксусная кислота) + HCl

- **Образование ангидрида (сцепление 2-х кислот) — (CH₃–CO)₂O:**
	  - 2CH₃COOH → (P₂O₅, t) (CH₃CO)₂O + H₂O

---

**Отдельно качественные реакции метановой/муравьиной кислоты:**

Муравьиная кислота является наиболее сильной среди других карбоновых кислот. Важным отличием является то, что она имеет альдегидную группу **H–C(=O)**OH, в связи с чем проявляет свойства альдегида, поэтому для неё характерны качественные реакции с:

- **Аммиачным раствором Ag₂O (реакция «серебряного зеркала»)**
	  - HCOOH + Ag₂O (аммиачный р-р) → 2Ag (осадок) + CO₂ (выделение газа) + H₂O
	  - На стенках пробирки выделяется чистое металлическое серебро в виде блестящего налёта (зеркала).

- **Cu(OH)₂**
	  - HCOOH + Cu(OH)₂ → (t) Cu₂O + CO₂ + H₂O
	  - Выпадает кирпично-красный осадок оксида меди.

---

**Получение карбоновых кислот:**

- **Применяется в промышленности** — «рвёт» цепь алкана пополам:
	  - CH₃–CH₂–CH₂–CH₃ (бутан) → (O₂, t) 2CH₃COOH + H₂O

- **Получение из альдегидов:**
	  - CH₃–CHO + Ag₂O (аммиачный р-р) → (t) CH₃COOH + 2Ag (осадок)
	  - CH₃–CH₂–CHO + Ag₂O (аммиачный р-р) → (t) C₂H₅COOH + 2Ag (осадок)
	  - CH₃–CHO + 2Cu(OH)₂ → CH₃COOH + Cu₂O + 2H₂O

- **Получение из спиртов:**
	  - CH₃–CH₂OH + KMnO₄ + H₂SO₄ → (t) CH₃COOH + MnSO₄ + K₂SO₄ + H₂O

- **Получение из алкенов** (концевой =CH₂, где двойная связь, разрушается до CO₂ и H₂O):
	  - 5CH₃–CH₂–CH=CH₂ + 8KMnO₄ + 12H₂SO₄ → 5CH₃–CH₂–COOH + 5CO₂ + 8MnSO₄ + 4K₂SO₄ + 17H₂O

- **Получение из алкинов** (концевой ≡CH, где тройная связь, разрушается до CO₂ и H₂O):
	  - CH₃–CH₂–C≡CH + 2KMnO₄ + 3H₂SO₄ → CH₃–CH₂–COOH + CO₂ + 2MnSO₄ + K₂SO₄ + 2H₂O
