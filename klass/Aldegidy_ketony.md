# Альдегиды и кетоны

#кислородосодержащая_органика

Химические соединения, содержащие в своём строении **карбонильную (C=O)** функциональную группу.

**ВАЖНО!** Главное отличие в строении **альдегида** от **кетона:**
- у **альдегида** группа C=O находится ==всегда **в конце**== структуры соединения
- у **кетона** группа C=O находится ==всегда **в середине**== структуры соединения

---

**Общая формула:**
- CₙH₂ₙO
- Для кетонов n ≥ 3, так как формула R–C(=O)–R'

---

**Таблица сравнения взаимодействий:**

| Признак | Альдегиды | Кетоны |
|---|---|---|
| **Строение** | R–CHO (карбонил у конца цепи) | R–CO–R' (карбонил в середине) |
| **Окисление** | Легко окисляются до кислот | Устойчивы к окислению |
| **Реакция «серебряного зеркала»** | **ДА** (качественная реакция) | **НЕТ** |
| **С Cu(OH)₂** | **ДА** (при нагревании Cu₂O↓ красный) | **НЕТ** |
| **Присоединение HCN** | Дают циангидрины | Дают циангидрины |
| **Гидрирование** | Первичные спирты | Вторичные спирты |

# Альдегиды

**Гомологический ряд** (тривиальные названия образуются от соответствующих кислот):

| Формула | Название |
|---|---|
| H–CHO (CH₂O) | метаналь / формальдегид (муравьиный альдегид) |
| CH₃–CHO (C₂H₄O) | этаналь (уксусный альдегид) |
| CH₃–CH₂–CHO (C₃H₆O) | пропаналь (пропионовый альдегид) |
| CH₃–CH₂–CH₂–CHO (C₄H₈O) | бутаналь (масляный альдегид) |
| CH₃–CH₂–CH₂–CH₂–CHO (C₅H₁₀O) | пентаналь (валериановый альдегид) |
| CH₃–CH₂–CH₂–CH₂–CH₂–CHO (C₆H₁₂O) | гексаналь (капроновый альдегид) |

---

**Изомерия альдегидов:**

| Вид изомерии | Описание | Пример |
|---|---|---|
| **Структурная** |  |  |
| **1. Изомерия углеродного скелета** | Меняется строение радикала, связанного с альдегидной группой (–CHO). Альдегидная группа всегда находится на конце цепи, поэтому **изомерия положения для неё невозможна**. | **Бутаналь** (CH₃–CH₂–CH₂–CHO) и **2-метилпропаналь** ((CH₃)₂CH–CHO) |
| **2. Межклассовая изомерия** | Альдегиды изомерны кетонам, а также непредельным спиртам и циклическим оксидам (для некоторых). Общая формула: CₙH₂ₙO. | **Пропаналь** (CH₃–CH₂–CHO) и **пропанон (ацетон)** (CH₃–C(O)–CH₃) |
| **3. Изомерия положения кратной связи** (для непредельных альдегидов) | Если в радикале есть двойная связь, она может находиться в разных положениях. | **Бутен-2-аль** (CH₃–CH=CH–CHO) и **бутен-3-аль** (CH₂=CH–CH₂–CHO) |

---

**Реакции и взаимодействия:**

- **Гидрирование, восстановление** (водород бьёт по =O, то есть по двойной связи с кислородом):
	  - CH₃–CHO + H₂ → (Ni, t) CH₃–CH₂OH (этанол)

- **Присоединение синильной кислоты (HCN)**
	  - CH₃–CHO + HCN → CH₃–CH(OH)–CN (2-гидроксипропаннитрил / лактонитрил)
	  - CH₃–CH(OH)–CN + H₂O + HCl → CH₃–CH(OH)–COOH + NH₄Cl

- **Присоединение гидросульфита натрия NaHSO₃**
	  - CH₃–CHO + NaHSO₃ → CH₃–CH(OH)–SO₃Na (осадок — кристаллы белого цвета)

- **Галогенирование**
	  - CH₃–CHO + Cl₂ → CH₂Cl–CHO + HCl

- **Гидратация** (образование 2-х групп –OH)
	  - CH₃–CHO + H₂O → CH₃–CH(OH)₂ (этандиол-1,1)

- **Реакция со спиртами с образованием ацеталей**
	  - CH₃–CHO + 2C₂H₅OH → CH₃–CH(OC₂H₅)–OC₂H₅ (1,1-диэтилацеталь)

- **Качественные реакции:**
	  - Реакция окисления с Cu(OH)₂ с образованием карбоновой кислоты:
	    - CH₃–CHO + Cu(OH)₂ → (t) CH₃COOH + Cu₂O + H₂O
	  - Реакция окисления (реакция «серебряного зеркала») с Ag₂O (аммиачный р-р) с образованием карбоновой кислоты:
	    - CH₃–CHO + Ag₂O (аммиач. р-р) → (t) CH₃COOH + 2Ag

- **Реакция окисления с образованием кислоты:**
	  - 3CH₃CHO + 2KMnO₄ + H₂SO₄ → 3CH₃COOH + K₂SO₄ + 2MnSO₄ + H₂O

- **Альдольная конденсация** (альдегид + альдегид), связь =O первого альдегида меняется на группу –OH, далее присоединяется второй альдегид с сохранением альдегидной группы:
	  - CH₃–CHO + C₂H₅–CHO → CH₃–CH(OH)–C₂H₅–CHO (4-гидроксипентаналь)

- **Полимеризация формальдегида:**
	  - nHCHO → (–CH₂–O–)ₙ (полиформальдегид)

---

**Получение альдегидов:**

- **Из спиртов**
	  - Реакция окисления с CuO с образованием альдегида (качественная реакция)
	    - CH₃–CH₂(OH) + CuO → (t) CH₃–C(=O)H (альдегид — этаналь) + Cu («медный блеск») + H₂O
	    - CH₃OH + CuO → (t) H–C(=O)H (метаналь) + Cu + H₂O

- **Из ацетилена (синтез Кучерова)**
	  - HC≡CH + H₂O → (Hg, t) CH₃–CHO

- **Гидроформилирование** (промышленный способ из алкена)
	  - C₂H₄ + CO + H₂ → CH₃–CH₂–CHO

---

**Цепочки реакций:**

- Al₄C₃ → CH₄ → C₂H₂ → CH₃–CHO → CH₃–CH₂OH → CH₃–CHO → CH₂Cl–CHO
- CaC₂ → C₂H₂ → C₂H₄ → C₂H₅OH → CH₃–CHO → CH₃–COOH
- карбид кальция → ацетилен → этилен → хлорэтан → этанол → уксусный альдегид → этанол → этен
- этан → этен → пропаналь → пропионовая кислота

# Кетоны
---

**Изомерия кетонов:**

| Вид изомерии | Описание | Пример |
|---|---|---|
| **1. Изомерия положения карбонильной группы (C=O)** | Карбонильная группа может находиться в разных местах углеродной цепи (кроме конца цепи, иначе получится альдегид). | **Бутанон-2** (CH₃–C(O)–CH₂–CH₃) и **пентанон-2** (CH₃–C(O)–CH₂–CH₂–CH₃); для пентанона есть также изомер положения: **пентанон-3** (CH₃–CH₂–C(O)–CH₂–CH₃) |
| **2. Изомерия углеродного скелета** | Меняется строение углеродных радикалов, связанных с карбонильной группой. | **Пентанон-2** (CH₃–C(O)–CH₂–CH₂–CH₃) и **3-метилбутанон-2** ((CH₃)₂CH–C(O)–CH₃) |
| **3. Межклассовая изомерия** | Кетоны изомерны альдегидам, непредельным спиртам и циклическим оксидам. | **Пропанон (ацетон)** (CH₃–C(O)–CH₃) и **пропаналь** (CH₃–CH₂–CHO) |

---

**Гомологический ряд:**

| Формула | Название |
|---|---|
| CH₃–C(=O)–CH₃ (C₃H₆O) | пропанон (ацетон) |
| CH₃–C(=O)–CH₂–CH₃ (C₄H₈O) | бутанон (метилэтилкетон) |
| CH₃–C(=O)–CH₂–CH₂–CH₃ (C₅H₁₀O) | пентанон (метилпропилкетон) |

---

**Реакции и взаимодействия:**

- **Гидрирование (восстановление) до вторичного спирта:**
	  - CH₃–C(=O)–CH₃ + H₂ → (Ni, t) CH₃–CH(OH)–CH₃ (изопропанол)

- **Присоединение синильной кислоты HCN (образование циангидринов):**
	  - CH₃–C(=O)–CH₃ + HCN → (CH₃)₂C(OH)CN (гидроксиметилпропаннитрил)

- **Присоединение гидросульфита натрия (NaHSO₃)**
	  - CH₃–C(=O)–CH₃ + NaHSO₃ → CH₃–CH(OH)–CH₂–SO₃Na (гидросульфит ацетона)

- **Реакция горения (окисление)**

- **Жёсткое окисление (с образованием карбоновых кислот)**
	  - 5CH₃–C(=O)–CH₃ + 8KMnO₄ + 12H₂SO₄ → (t) 5CH₃–CH₂–COOH + 5CO₂ + 4K₂SO₄ + 8MnSO₄ + 12H₂O

- **Галогенирование:**
	  - CH₃–C(=O)–CH₃ + Br₂ → (H⁺) Br–CH₂–C(=O)–CH₃ + HBr

**ВАЖНО!** Кетоны **НЕ** взаимодействуют с Ag₂O, соответственно, не участвуют в реакции «серебряного зеркала», а также с Cu(OH)₂ — это **главное отличие** от альдегидов, для которых эти реакции являются **качественными**.

---

**Получение:**

- **Окисление вторичных спиртов:**
	  - CH₃–CH(OH)–CH₃ + CuO → CH₃–C(=O)–CH₃ + Cu + H₂O

- **Дегидрирование вторичных спиртов:**
	  - CH₃–CH(OH)–CH₃ → (Ag, t) CH₃–C(=O)–CH₃ + H₂

- **Пиролиз солей карбоновых кислот:**
	  - (CH₃COO)₂Ca → CH₃–C(=O)–CH₃ + CaCO₃

- **Промышленный способ:**
	  - Гидратация гомологов ацетилена (реакция Кучерова)
	    - CH₃–C≡CH + H₂O → (H₂SO₄) CH₃–C(=O)–CH₃
