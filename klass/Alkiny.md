# Алкины

#углеводороды_органика

**Общая формула:** CₙH₂ₙ₋₂

HC≡CH

**Примеры:** C₂H₂ (ацетилен), C₃H₄ (пропин), C₄H₆ (бутин), C₅H₈ (пентин), C₆H₁₀ (гексин), C₇H₁₂ (гептин)

---

**Получение алкинов**

- **Карбидный способ**
	  - CaC₂ + 2H₂O → HC≡CH + Ca(OH)₂

- **Термическое разложение**
	  - 2CH₄ → (условие: темп. 1200 °C) HC≡CH + 3H₂

- **Реакция дегидрогалогенирования**
	  - CH₂(Br)–CH₂(Br) + 2KOH → HC≡CH + 2KBr + 2H₂O

- **Гидролиз**
	  - Al₄C₃ → (условия: H₂O) C₂H₂
	  - CaC₂ → (условия: H₂O) C₂H₂

- **Окисление**

**Изомерия алкинов:**

| Вид изомерии | Описание | Примеры |
|---|---|---|
| **Изомерия углеродного скелета** | Разветвление цепи. | C₅H₈:<br>1. **пентин-1** (CH≡C–CH₂–CH₂–CH₃)<br>2. **3-метилбутин-1** (CH≡C–CH(CH₃)–CH₃) |
| **Изомерия положения тройной связи** | Тройная связь находится между разными атомами углерода. | C₅H₈:<br>1. **пентин-1** (CH≡C–CH₂–CH₂–CH₃)<br>2. **пентин-2** (CH₃–C≡C–CH₂–CH₃) |
| **Межклассовая изомерия** | Алкины изомерны **алкадиенам** (и некоторым циклоалкенам), т.к. у них одинаковая общая формула. | C₄H₆:<br>1. Алкин: **бутин-1** (CH≡C–CH₂–CH₃)<br>2. Алкадиен: **бутадиен-1,3** (CH₂=CH–CH=CH₂) |

---

**Реакции и взаимодействия:**

- **Гидрирование**
	  - HC≡CH + H₂ → (условия: темп. и Ni) CH₂=CH₂
	  - CH₂=CH₂ + H₂ → (условия: темп. и Ni) CH₃–CH₃

- **Галогенирование** (используется хлорная или бромная вода)
	  - HC≡CH + Br₂ → CH(Br)=CH(Br)
	  - CH(Br)=CH(Br) + Br₂ → (Br)CH(Br)–(Br)CH(Br)

- **Гидрогалогенирование** (по правилу Марковникова)
	  - HC≡CH + HCl → CH₂=CHCl
	  - CH₃–C≡CH + HBr → CH₃–C(Br)=CH₂
	  - CH₃–C(Br)=CH₂ + HBr → CH₃–(Br)C(Br)–CH₃ (2,2-дибромпропан)

- **Гидратация (Синтез Кучерова)**
	  - HC≡CH + H–OH → (условия: Hg²⁺) CH₃–C(=O)–H (ацетальдегид / уксусный альдегид)
	  - HC≡CH–CH₃ + H–OH → (условия: Hg²⁺) CH₃–C(=O)–CH₃ (диметилкетон / пропанон / ацетон)

- **Реакция полимеризации**
	  - 2HC≡CH → (условия: NH₄Cl, CuCl) CH₂=CH–C≡CH
	  - CH₂=CH–C≡CH + HCl → CH₂=CH–C(Cl)=CH₂ (винилацетилен)

- **Циклополимеризация**
	  - 3HC≡CH → (условия: уголь и 600 °C) бензол (C₆H₆)

- **Реакция полного окисления / горение**

- **Реакция неполного окисления** (с перманганатом калия)
	  - CH₃–C≡CH + KMnO₄ + H₂O → (t) CH₃–COOH + CO₂ + MnO₂ + KOH

- **Качественная реакция с аммиачным раствором Ag₂O** для алкинов с терминальной тройной связью (то есть на конце R–C≡CH или CH≡C–R) — в рамках реакции происходит замещение атома H:
	  - CH₃–C≡CH + Ag₂O (аммиачный раствор) → CH₃–C≡CAg + H₂O

---

**Качественные реакции по обнаружению тройной связи**

- Ag₂O(NH₃) = [Ag(NH₃)₂]OH
- CuCl(NH₃) = [Cu(NH₃)₂]Cl
- HC≡CH + 2CuCl → Cu–C≡C–Cu (осадок) + 2H₂O
- CH₃–C≡CH + CuCl → CH₃–C≡C–Cu (осадок) + HCl
- HC≡CH + Ag₂O → Ag–C≡C–Ag (осадок), (ацетиленид серебра) + H₂O

**Как различить?**

- Если попадаются алкан и алкен, то использовать Br₂ и KMnO₄
- Если попадаются алкан и алкин, то использовать Br₂

**Сравнение углеводородов:**

| Признак | Алканы | Алкены | Алкины |
|---|---|---|---|
| Общая формула | CₙH₂ₙ₊₂ | CₙH₂ₙ | CₙH₂ₙ₋₂ |
| Тип связи | одинарная (σ) | двойная (σ + π) | тройная (σ + 2π) |
| Реакция с Br₂ (вода) | нет | обесцвечивание | обесцвечивание |
| Реакция с KMnO₄ | нет | обесцвечивание | обесцвечивание |
| Реакция с Ag₂O (аммиачный раствор) | нет | нет | осадок (для терминальных алкинов) |
| Тип реакций | замещение | присоединение | присоединение |

**Промышленное получение алкинов**

- 6CH₄ + O₂ → 2C₂H₂ + 2CO + 10H₂ (термоокислительный пиролиз метана)
- 2CH₄ → (условие: t 1500 °C) C₂H₂ + 3H₂
- CaC₂ + 2H₂O → C₂H₂ + Ca(OH)₂ (гидролиз карбида кальция)
