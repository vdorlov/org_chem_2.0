# Предельные спирты

#кислородосодержащая_органика

**Спирты** — производные углеводородов, молекулы которых содержат одну или несколько гидроксильных групп (–OH).

Если все атомы углерода в молекуле спирта находятся в состоянии sp³-гибридизации (то есть **НЕ** имеют двойных и тройных связей) — то это и будут предельные спирты с единой формулой:
- CₙH₂ₙ₊₁OH
- CₙH₂ₙ₊₂O
- CₙH₂ₙ₊₂₋ₘ(OH)ₘ, n — число атомов углерода, m — число гидроксильных групп (они и определяют атомность спирта — одноатомный, двухатомный, многоатомный)

---

**Гомологический ряд одноатомных спиртов:**

| Формула | Название |
|---|---|
| CH₃OH | метанол (метиловый спирт) |
| C₂H₅OH | этанол (этиловый спирт) |
| C₃H₇OH | пропанол (пропиловый спирт) |
| C₄H₉OH | бутанол (бутиловый спирт) |

---

**Гомологический ряд многоатомных спиртов:**

| Формула | Название |
|---|---|
| HO–CH₂–CH₂–OH | этандиол-1,2 (этиленгликоль) |
| HO–CH₂–CH(OH)–CH₂–OH | пропантриол-1,2,3 (глицерин) |

**Первичный спирт:**
CH₃–CH₂–CH₂(OH) — пропанол-1

**Вторичный спирт:**
CH₃–CH(OH)–CH₃ — пропанол-2

**ВАЖНО!** Спирты можно спутать с простыми эфирами:

- Общая формула C₂H₆O
	  - CH₃–CH₂(OH) — этиловый спирт / этанол
	  - CH₃–O–CH₃ — диметиловый эфир / метилметаноат

- Общая формула C₃H₈O
	  - CH₃–CH(OH)–CH₃ — пропиловый спирт / пропанол-2
	  - CH₃–O–CH₂–CH₃ — метилэтаноат

---

**Изомерия спиртов:**

| Вид изомерии | Описание | Пример |
|---|---|---|
| **Структурная** |  |  |
| **1. Изомерия положения гидроксильной группы (OH)** | Меняется положение OH-группы в углеродной цепи. | **Бутанол-1** (CH₃–CH₂–CH₂–CH₂OH) и **бутанол-2** (CH₃–CH₂–CH(OH)–CH₃) |
| **2. Изомерия углеродного скелета** | Меняется строение углеродной цепи (разветвлённая или линейная). | **Бутанол-1** (CH₃–CH₂–CH₂–CH₂OH) и **2-метилпропанол-1** ((CH₃)₂CH–CH₂OH) (изобутиловый спирт) |
| **3. Межклассовая изомерия** | Спирты изомерны простым эфирам. Общая формула: CₙH₂ₙ₊₂O. | **Этанол** (C₂H₅OH) и **диметиловый эфир** (CH₃–O–CH₃) |
| **Пространственная** |  |  |
| **4. Оптическая изомерия (энантиомерия)** | Возникает, если есть **асимметрический атом углерода** (атом C, связанный с 4 разными заместителями). | **Бутанол-2** (CH₃–CH₂–CH(OH)–CH₃) имеет хиральный центр (второй атом углерода). Существует в виде двух зеркальных изомеров. |

---

**Реакции и взаимодействия одноатомных спиртов:**

- **Реакция замещения с K и Na**
	  - C₂H₅OH + Na → C₂H₅ONa (этилат натрия) + H₂
	  - C₂H₅ONa + H₂O → NaOH + C₂H₅OH (обратная реакция на получение спирта)

- **Реакция замещения с галогеноводородами и галогенпроизводными (PCl₅)**
	  - CH₃–CH₂–CH₂(OH) + PCl₅ → CH₃–CH₂–CH₂Cl + HCl + POCl₃ (оксихлорид фосфора)
	  - CH₃–CH₂(OH) + HCl → CH₃–CH₂Cl + H₂O

- **Окисление с катализатором H₂SO₄**
	  - C₃H₇OH → (H₂SO₄, **t > 180**) C₃H₆ (пропен) + H₂O
	  - 2C₃H₇OH → (H₂SO₄, **t < 140**) C₃H₇–O–C₃H₇ (дипропиловый простой эфир / пропилпропаноат) + H₂O

- **Реакция горения**

- **Реакция окисления с CuO с образованием альдегида (качественная реакция)**
	  - CH₃–CH₂(OH) + CuO → (t) CH₃–C(=O)H (альдегид — этаналь) + Cu («медный блеск») + H₂O
	  - CH₃OH + CuO → (t) H–C(=O)H (метаналь) + Cu + H₂O
  - В рамках данной реакции на примере CH₃–CH**H**–O**H** отщепляются 2 водорода, а конец –CH–O превращается в альдегид C(=O)H

- **Взаимодействие с органическими кислотами с образованием сложных эфиров (этерификация)**
	  - C₂H₅OH + H–C(=O)O**H** → H–C(=O)OC₂H₅ (этиловый эфир муравьиной кислоты / этилформиат)

**ВАЖНО!** Спирты не взаимодействуют с **щелочами**, водородом, водой, солями, галогенами.

---

**Получение спиртов:**
	- CH₃–CH=CH₂ + H–OH → CH₃–CH(OH)–CH₃
	- C₂H₅Cl + NaOH → NaCl + C₂H₅OH
	- CH₃–CH₂–C(=O)H (пропаналь) + H₂ → (Ni, t) CH₃–CH₂–CH₂(OH)
	- CH₃–C(=O)–CH₃ (пропанон / ацетон) + H₂ → (Ni, t) CH₃–CH(OH)–CH₃

**Промышленные способы получения спиртов:**
	- C₂H₄ + H–OH → (t) C₂H₅OH
	- CO + 2H₂ → (t) CH₃OH

**Физиологический способ:**
	- C₆H₁₂O₆ → (ферменты) 2C₂H₅OH + CO₂

---

**Реакции и взаимодействия многоатомных спиртов:**

- **Взаимодействие глицерина с Na:**
	  - 2HO–CH₂–CH(OH)–CH₂–OH + 6Na → 2NaO–CH₂–CH(ONa)–CH₂–ONa + 3H₂

- **Взаимодействие с Cu(OH)₂ (качественная реакция на многоатомные спирты):**
	  - HO–CH₂–CH₂–OH + Cu(OH)₂ → ярко-синий раствор (гликолят меди)
	  - Образуется комплексное соединение синего цвета

- **Нитрование многоатомных спиртов:**
	  - HO–CH₂–CH(OH)–CH₂–OH + 3HNO₃ → O₂NO–CH₂–CH(ONO₂)–CH₂–ONO₂ (нитроглицерин) + 3H₂O

- **Взаимодействие этиленгликоля с гидроксидом меди:**
	  - HO–CH₂–CH₂–OH + Cu(OH)₂ → синий раствор гликолята меди

---

**Получение многоатомных спиртов:**
	- CH₂=CH₂ + KMnO₄ + H₂O → CH₂OH–CH₂OH + KOH + MnO₂
	- CH₂Cl–CH₂Cl + NaOH → 2NaCl + CH₂OH–CH₂OH

---

**Цепочки реакций:**

- C₃H₈ → C₃H₆ → C₃H₇OH → C₃H₆ → C₃H₇Cl → C₃H₇OH → C₃H₇ONa → C₃H₇OH
- C₂H₆ → C₂H₄ → C₂H₅OH → C₂H₄ → C₂H₅Cl → C₂H₅OH → C₂H₅ONa → C₂H₅OH
- C₃H₆ → C₃H₈ → C₃H₆ → C₃H₇OH → пропанон
- C₃H₆ → C₃H₇OH → пропанон → пропанол-2
- метан → ацетилен → этаналь → этанол → бромэтан → этилен → этанол → этаналь
