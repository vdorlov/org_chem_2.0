# Арены (ароматические углеводороды)

#углеводороды_органика

**Общая формула:** CₙH₂ₙ₋₆

Углеводороды, молекулы которых содержат бензольные кольца.
Основной представитель — бензол (C₆H₆).
Производные бензола: толуол (метилбензол), ксилол (1,2/1,3/1,4-диметилбензол), кумол, стирол.

Каждый атом углерода в бензольном кольце находится в состоянии sp²-гибридизации.

**Строение бензола:**

```
      H
      |
  H—C   C—H
    //   \\
   C       C
    \     /
     C—C
      |
      H
```

Бензол — плоский шестиугольник, все связи C–C одинаковы (ароматическая система, длина ~0,140 нм).

---

**Изомерия аренов:**

| Вид изомерии | Описание | Примеры |
|---|---|---|
| **Изомерия положения заместителей** | Для дизамещённых бензолов (например, C₆H₄R₂) возможны три изомера: орто- (1,2-), мета- (1,3-) и пара- (1,4-). | C₆H₄(CH₃)₂ (диметилбензол, ксилол):<br>1. **орто-ксилол** (1,2-диметилбензол)<br>2. **мета-ксилол** (1,3-диметилбензол)<br>3. **пара-ксилол** (1,4-диметилбензол) |
| **Изомерия углеродного скелета** (боковой цепи) | Для алкилбензолов возможно разветвление алкильного радикала. | C₈H₁₀:<br>1. **этилбензол** (C₆H₅–CH₂–CH₃)<br>2. **1,2-диметилбензол** (орто-ксилол) — *здесь меняется не цепь, а положение, но это тоже вид скелетной изомерии* |
| **Межклассовая изомерия** | Арены с общей формулой CₙH₂ₙ₋₆ (n ≥ 6) могут иметь изомеры среди непредельных циклических и ациклических соединений (в школьном курсе обычно не рассматриваются глубоко). | C₆H₆:<br>1. Арен: **бензол**<br>2. (Теоретически) Циклогексатриен? Но бензол стабильнее. |

---

**Реакции и взаимодействия:**

- **Гидрирование** (получение циклогексана)
	  - C₆H₆ + 3H₂ → (условие: Ni, t) C₆H₁₂ (циклогексан)

- **Галогенирование (присоединение)**
	  - C₆H₆ + 3Cl₂ → (условие: УФ) C₆H₆Cl₆ (гексахлорциклогексан)
	  - C₆H₆ + Cl₂ → (условие: кат. FeCl₃) C₆H₅Cl (хлорбензол) + HCl

- **Нитрование** (+HO–NO₂, присоединяется группа NO₂ к бензолу)
	  - C₆H₆ + HO–NO₂ → (условие: конц. H₂SO₄, t) C₆H₅NO₂ (нитробензол) + H₂O

- **Сульфирование** (+HO–SO₃H, присоединяется SO₃H группа кислоты к бензолу)
	  - C₆H₆ + HO–SO₃H → (условие: конц. H₂SO₄, t) C₆H₅SO₃H (бензолсульфокислота) + H₂O

- **Алкилирование**
	  - C₆H₆ + CH₃Cl → (условие: кат. AlCl₃) C₆H₅CH₃ (толуол) + HCl

- **Взаимодействие с алкеном**
	  - C₆H₆ + CH₂=CH₂ → (условие: кат. AlCl₃) C₆H₅–CH₂–CH₃ (этилбензол)

- **Окисление полное / горение**
	  - 2C₆H₆ + 15O₂ → 12CO₂ + 6H₂O

**Нет реакции:**
KMnO₄ (бензол не окисляется перманганатом, реакция проходит только по боковой цепи с его гомологами)

---

**Получение бензола:**

- **Тримеризация**
	  - 3C₂H₂ → (условия: уголь и темп. 600 °C) C₆H₆ (бензол (кольцо))

- **Дегидрирование циклогексана**
	  - C₆H₁₂ (циклогексан) → (условия: Pt, t) C₆H₆ (бензол (кольцо)) + 3H₂

- **Дегидрирование гексана (риформинг)**
	  - C₆H₁₄ (гексан) → (условия: Pt, t) C₆H₆ (бензол (кольцо)) + 4H₂

- **Декарбоксилирование бензоата натрия**
	  - C₆H₅–COONa + NaOH → Na₂CO₃ + C₆H₆ (бензол (кольцо))

---

**Реакции толуола (C₆H₅–CH₃)**
	- C₆H₅–CH₃ + KMnO₄ + H₂O → C₆H₅–C(=O)–OH (бензойная кислота) + KOH + MnO₂
	- C₆H₅–CH₃ + KMnO₄ + H₂SO₄ → C₆H₅–C(=O)–OH (бензойная кислота) + K₂SO₄ + MnSO₄ + H₂O
	- C₆H₅–CH₃ + Cl₂ → (при условии: свет) C₆H₅–CH₂(Cl) + HCl
	- C₆H₅–CH₃ + KMnO₄ → (при условии: t) C₆H₅–C(=O)–OK
	- C₆H₅–C(=O)OK + HCl → C₆H₅–C(=O)–OH + KCl

**Бензойная кислота:** C₆H₅–COOH

**Реакции ксилола (C₆H₄(CH₃)₂)**
	- C₆H₄(CH₃)₂ (метилы в позициях 1 и 3 кольца) + KMnO₄ + H₂O → C₆H₄(COOH)₂ (фталевая кислота) + KOH + MnO₂
	- C₆H₄(CH₃)₂ (метилы в позициях 1 и 3 кольца) + KMnO₄ + H₂SO₄ → C₆H₄(COOH)₂ (фталевая кислота) + K₂SO₄ + MnSO₄ + H₂O

- **Фталевая кислота:** C₆H₄(COOH)₂

**Реакции кумола (C₆H₅–CH₂–CH₃)**
	- C₆H₅–CH₂–CH₃ (последний метильный остаток отщепляется и сгорает (CO₂)) + KMnO₄ + H₂O → C₆H₅–C(=O)–OH (бензойная кислота) + CO₂ + KOH + MnO₂
	- C₆H₅–CH₂–CH₃ (последний метильный остаток отщепляется и сгорает (CO₂)) + H₂SO₄ + KMnO₄ → C₆H₅–C(=O)–OH (бензойная кислота) + CO₂ + K₂SO₄ + MnSO₄ + H₂O
	- C₆H₅–CH₂–CH₃ + Cl₂ → C₆H₅–CH(Cl)–CH₃ + HCl
	- C₆H₅–CH(Cl)–CH₃ + KOH → C₆H₅–CH=CH₂ (стирол) + KCl + H₂O

**Реакции стирола (C₆H₅–CH=CH₂)**
	- nC₆H₅–CH=CH₂ → (–C₆H₅–CH–CH₂–)ₙ (полистирол)
	- Реакция без нагревания: C₆H₅–CH=CH₂ + KMnO₄ + H₂O → C₆H₅–CH(OH)–CH(OH) (1-фенилэтандиол-1,2)
	- Реакция с нагреванием: C₆H₅–CH=CH₂ + KMnO₄ → C₆H₅–C(=O)–OH (бензойная кислота) + CO₂ + H₂O

---

**Промышленное получение аренов**

Бензол получают из каменного угля (коксохимическое производство).
Из нефти (бензиновая фракция):
C₆H₁₄ → C₆H₆ + 4H₂ (каталитический риформинг)

**Примеры цепочек:**

- CH₄ → C₂H₂ → C₆H₆ → C₆H₅–C₂H₅ → C₆H₅–C₂H₄Cl → C₆H₅–C₂H₃ → фенилэтандиол
- CaC₂ → C₂H₂ → C₆H₆ → C₆H₅–C₂H₅ → C₆H₅–C₂H₄Cl → C₆H₅–C₂H₃ → бензойная кислота
- C₃H₈ --Br₂→ X₁ --KOH→ X₂ → C₃H₆ --Br₂→ X₃ --KOH→ X₄
- C₂H₄ → C₂H₄Cl₂ --KOH→ X₁ --C→ X₂ --CH₃Cl→ X₃ → C₆H₅–COOH
