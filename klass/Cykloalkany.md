# Циклоалканы

#углеводороды_органика

**Общая формула:** CₙH₂ₙ

Насыщенные углеводороды, содержащие цикл из 3-х и более атомов углерода.
Циклоалканы изомерны соответствующим алкенам.

---

**Характерные реакции** (как для насыщенных углеводородов): замещение (Cl₂), дегидрирование (+H₂), разложение и окисление

- C₄H₈ (циклобутан) + H₂ → CH₃–CH₂–CH₂–CH₃ (н-бутан) (катализатор (Ni, Pt, Pd), нагревание)
- C₄H₈ + Cl₂ → C₄H₇Cl (хлорциклобутан) + HCl (сохранение цикла)
- C₄H₈ + Cl₂ → Cl–CH₂–CH₂–CH₂–CH₂–Cl (1,4-дихлорбутан)
- C₄H₈ (циклобутан) → 2CH₂=CH₂ (этилен) (разложение (крекинг, пиролиз)), высокая температура (500–800 °C)
- C₄H₈ + O₂ → CO₂ + H₂O

---

**Изомерия циклоалканов:**

| Вид изомерии                      | Описание                                                                                                                       | Примеры                                                                                                           |
| --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| **Изомерия углеродного скелета**  | Изменение размера цикла или строения заместителей в боковой цепи.                                                              | C₅H₁₀:<br>1. **циклопентан**<br>2. **метилциклобутан**<br>3. **этилциклопропан**                                  |
| **Межклассовая изомерия**         | Циклоалканы изомерны **алкенам** (так как общая формула одна — CₙH₂ₙ).                                                         | C₄H₈:<br>1. Циклоалкан: **циклобутан**<br>2. Алкен: **бутен-1** (CH₂=CH–CH₂–CH₃)                                  |
| **Пространственная (цис-транс-)** | Возможна для дизамещённых циклов, когда заместители расположены по одну (цис-) или по разные стороны (транс-) плоскости цикла. | **1,2-диметилциклопропан**:<br>1. *цис-* (CH₃ группы с одной стороны)<br>2. *транс-* (CH₃ группы с разных сторон) |
