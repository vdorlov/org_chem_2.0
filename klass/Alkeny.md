**Изомерия алкенов:**

| Вид изомерии | Описание | Примеры |
|---|---|---|
| **Изомерия углеродного скелета** | Разветвление цепи, как у алканов, но с сохранением двойной связи. | C₅H₁₀:<br>1. **пентен-1** (CH₂=CH–CH₂–CH₂–CH₃)<br>2. **3-метилбутен-1** (CH₂=CH–CH(CH₃)–CH₃) |
| **Изомерия положения двойной связи** | Двойная связь находится между разными атомами углерода. | C₄H₈:<br>1. **бутен-1** (CH₂=CH–CH₂–CH₃)<br>2. **бутен-2** (CH₃–CH=CH–CH₃) |
| **Межклассовая изомерия** | Алкены изомерны **циклоалканам**. | C₄H₈:<br>1. Алкен: **бутен-1**<br>2. Циклоалкан: **циклобутан** |
| **Геометрическая (цис-транс-)** | Возможна, если у каждого атома углерода при двойной связи разные заместители. Разное положение в пространстве. | C₄H₈ (бутен-2):<br>1. *цис-бутен-2* (CH₃ группы по одну сторону)<br>2. *транс-бутен-2* (CH₃ группы по разные стороны) |

**Реакции и взаимодействия:**

- **Гидрирование**
	  - CH₂=CH₂ + H₂ → (условие: Ni) CH₃–CH₃

- **Присоединение галогенов / галогенирование (Cl₂, Br₂)**
	  - CH₂=CH₂ + Cl₂ → CH₂Cl–CH₂Cl
	  - CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br

- **Гидрогалогенирование (HCl, HBr)**
	  - CH₂=CH₂ + H–Cl → CH₃–CH₂Cl
	  - CH₂=CH₂ + H–Br → CH₃–CH₂Br

- **Гидратация (образование предельного одноатомного спирта)**
	  - CH₂=CH₂ + H–OH → (условие: температура) CH₃–CH₂(OH)

- **Полимеризация** (в реакции небольшие молекулы (мономеры) соединяются друг с другом, образуя длинные цепи или трёхмерные сетки (полимеры))
	  - nCH₂=CH₂ → (кат.) (–CH₂–CH₂–)ₙ
	  - nCH₂=CH–CH₃ → (кат.) (–CH₂–CH(CH₃)–)ₙ

- **Окисление полное (горение)**

- **Реакция Вагнера.** Окисление неполное под действием водного раствора KMnO₄. Происходит гидроксилирование алкенов с образованием диолов
	  - CH₂=CH₂ + KMnO₄ + H–OH → CH₂(OH)–CH₂(OH) (этандиол-1,2 / этиленгликоль) + MnO₂ + KOH

- **Реакция Вакера (окисление)** на получение альдегида
	  - 2CH₂=CH₂ + O₂ → 2CH₃CHO

---

**Правило Марковникова.** Водород присоединяется к более гидрогенизированному атому углерода, а электрофильная часть (несущая отрицательный заряд) — к менее гидрогенизированному.

- CH₂=CH–CH₃ + HCl / HBr / H–OH → реакция пойдёт на углеродах с двойной связью, при этом водород присоединится к тому углероду, который более гидрогенизирован, то есть имеет большее количество атомов водорода → CH₃–CH(Cl)–CH₃
-  Исключение из правила: H₂O₂ — выступает в роли катализатора
	- CH₃–CH=CH₂ + H–OH → (условие: H₂O₂) CH₃–CH(OH)–CH₃

---

**Как определить двойную связь?**

- Использовать Br₂ (вода, жёлтого цвета)
	  - C₂H₆ + Br₂ → реакции НЕТ (алканы взаимодействуют только с чистым бромом)
	  - CH₂=CH₂ + Br₂ → CH₂Br–CH₂Br

- Использовать KMnO₄ (раствор фиолетового цвета)
	  - с алканами взаимодействия нет
	  - CH₂=CH₂ + KMnO₄ + H–OH → CH₂OH–CH₂OH (этандиол), в процессе реакции происходит обесцвечивание перманганата калия

---

**Получение алкенов**

- **Из этанола**
	  - CH₃–CH₂–OH → (условие: конц. H₂SO₄, t > 140 °C) CH₂=CH₂ + H₂O

- **Из хлорэтана**
	  - CH₃–CH₂–Cl + KOH → CH₂=CH₂ + KCl + H₂O

- **Из бромэтана**
	  - CH₃–CH₂–Br + KOH → CH₂=CH₂ + KBr + H₂O

- **Из этана (дегидрирование)**
	  - CH₃–CH₃ → (условие: Cr₂O₃) CH₂=CH₂ + H₂

- **Правило Зайцева.** При дегидратации вторичных и третичных спиртов и при дегидрогалогенировании вторичных и третичных галогенидов водород отщепляется преимущественно от наименее гидрогенизированного атома углерода.
	  - CH₃–CH(OH)–CH₂–CH₃ → (условие: конц. H₂SO₄) CH₃–CH=CH–CH₃ + H₂O

- **Реакция с NaOH**
	  - CH₃–CH₂–CH(Br)–CH₃ → (условие: темп.) CH₃–CH=CH–CH₃ + NaBr + H₂O

**Промышленное получение алкенов**

C₂H₄ (исходное вещество C₂H₆, получают дегидрированием этана).
