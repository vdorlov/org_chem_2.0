# Амины

#азотосодержащая_органика

Производные аммиака (NH₃), в молекулах которых атомы водорода замещены на аминогруппу (–NH₂).

Амины, выступая в роли производных аммиака, который обладает основными свойствами, являются органическими основаниями.
Реагируют с кислотами и их производными, галогеналканами и спиртами. Большинство аминов малорастворимы в воде.

**ВАЖНО!** Амины горят на воздухе с образованием углекислого газа, воды и азота.

Для аминов характерен резкий неприятный запах.
В производстве используются для создания высокомолекулярных соединений (каучуки), красителей, взрывчатых и лекарственных веществ.

---

**Сила аминов:**

C₆H₅NH₂ < NH₃ < CH₃NH₂ < (CH₃)₂NH

---

**Общая формула:**
- CₙH₂ₙ₊₁NH₂
- CₙH₂ₙ₊₃N

---

**Классификация аминов:**

- **Первичные** (по количеству заместителей при азоте)
	  - CH₃–CH₂–CH₂–NH₂ (пропанамин-1)

- **Вторичные** (по количеству заместителей при азоте)
	  - CH₃–NH–CH₂–CH₃ (метилэтиламин)

- **Третичные** (по количеству заместителей при азоте)
	  - CH₃–N(CH₃)–CH₃ (триметиламин)

- **Ароматический амин**
	  - C₆H₅–NH₂ (анилин / фениламин)

  **Строение анилина:**
  ```
        NH₂
        |
    H—C   C—H
      //   \\
     C       C
      \     /
       C—C
        |
        H
  ```

- **Циклический амин**
	  - C₆H₁₁–NH₂ (циклогексиламин)

  **Строение циклогексиламина:**
  ```
       CH₂—CH₂
      /       \
   CH₂         CH₂
      \       /
       CH₂—CH₂
          |
          NH₂
  ```

---

**Изомерия аминов:**

| Вид изомерии | Описание | Примеры |
|---|---|---|
| **Изомерия углеродного скелета** | Разветвление углеводородной цепи, связанной с азотом (как у алканов). Характерна для всех типов аминов. | C₄H₁₁N:<br>1. **н-бутиламин** (CH₃–CH₂–CH₂–CH₂–NH₂)<br>2. **изобутиламин** ((CH₃)₂CH–CH₂–NH₂)<br>3. **втор-бутиламин** (CH₃–CH₂–CH(NH₂)–CH₃)<br>4. **трет-бутиламин** ((CH₃)₃C–NH₂) |
| **Изомерия положения аминогруппы** | Аминогруппа (–NH₂) находится у разных атомов углерода в цепи. Характерна только для **первичных аминов**. | C₄H₉NH₂:<br>1. **бутиламин** (аминогруппа у C1, CH₃–CH₂–CH₂–CH₂–NH₂)<br>2. **втор-бутиламин** (аминогруппа у C2, CH₃–CH₂–CH(NH₂)–CH₃)<br>*(Важно: иногда изомерию положения путают со скелетной, но здесь атом азота «путешествует» по цепи).* |
| **Изомерия типа амина (межклассовая внутри класса)** | Амины с одинаковой формулой могут принадлежать к разным подклассам: **первичные (R–NH₂), вторичные (R–NH–R′) и третичные (R–NR′–R″)**. Это главная «фишка» аминов. | C₃H₉N:<br>1. Первичный: **пропиламин** (CH₃–CH₂–CH₂–NH₂)<br>2. Первичный (изомер): **изопропиламин** ((CH₃)₂CH–NH₂)<br>3. Вторичный: **метилэтиламин** (CH₃–NH–CH₂–CH₃)<br>4. Третичный: **триметиламин** ((CH₃)₃N) |
| **Межклассовая изомерия** (с другими классами) | Амины могут быть изомерны некоторым другим азотсодержащим соединениям, например, предельным нитросоединениям (R–NO₂). Для ЕГЭ важно: амины могут быть изомерны друг другу (по типу), а с другими классами (например, с нитросоединениями) изомерия возможна, но формулы будут содержать разные атомы, поэтому в чистом виде межклассовая изомерия внутри класса аминов — это и есть изомерия типа (первичн–вторичн–третичн). | C₂H₇N:<br>1. Первичный амин: **этиламин** (CH₃–CH₂–NH₂)<br>2. Вторичный амин: **диметиламин** (CH₃–NH–CH₃)<br>(Третичный с двумя углеродами не построить). |

---

**Реакции и взаимодействия аминов:**

- **Реакция горения**
	  - 4CH₃NH₂ + 9O₂ → 4CO₂↑ + 10H₂O + 2N₂↑

- **Гидратация**
	  - C₂H₅NH₂ + H₂O → [C₂H₅NH₃]⁺OH⁻ (гидроксид этиламмония)
	  - CH₃NH₂ + H₂O → [CH₃NH₃]⁺OH⁻ (гидроксид метиламмония)
	    - AlCl₃ + [CH₃NH₃]OH → [CH₃NH₃]Cl + Al(OH)₃ (хлорид метиламмония)

- **Взаимодействие с кислотами (HNO₃, HCl, HBr, HI, H₂SO₄)**
	  - C₂H₅NH₂ + HNO₃ → [C₂H₅NH₃]NO₃ (нитрат этиламмония)
	  - C₂H₅NH₂ + HCl → [C₂H₅NH₃]Cl (хлорид этиламмония)
	  - C₂H₅NH₂ + HBr → [C₂H₅NH₃]Br (бромид этиламмония)
	  - C₂H₅NH₂ + H₂SO₄ → [C₂H₅NH₃]₂SO₄ (сульфат этиламмония)
	    - [C₂H₅NH₃]₂SO₄ + 2NaOH → 2C₂H₅NH₂ + Na₂SO₄ + 2H₂O

- **Щёлочи, как более сильные основания, вытесняют амины из их солей**
	  - [C₂H₅NH₃]₂SO₄ + NaOH → Na₂SO₄ + H₂O + C₂H₅NH₂ (этиламин)
	  - [C₂H₅NH₃]NO₃ + KOH → KNO₃ + H₂O + C₂H₅NH₂ (этиламин)

- **Взаимодействие с азотистой кислотой (HNO₂)** — качественная реакция для определения типа амина:
  - **Первичные амины** (образование спирта и выделение газа N₂):
    - C₂H₅NH₂ + OH–N=O (HNO₂ / азотистая кислота) → N₂ + H₂O + C₂H₅OH
  - **Вторичные амины:**
    - (CH₃)₂NH + OH–N=O (HNO₂ / азотистая кислота) → (CH₃)₂N–N=O (нитрозодиметиламин) + H₂O
  - **Третичные амины:**
    - НЕ РЕАГИРУЮТ

- **Алкилирование** (взаимодействие с галогеналканами) — реакция замещения атома водорода в аминогруппе на углеводородный радикал (позволяет получать вторичные и третичные амины):
	  - C₂H₅NH₂ + CH₃Cl → [C₂H₅–NH₂–CH₃]Cl (хлорид этилметиламмония)

- **Ацилирование** (реакция с карбоновыми кислотами и их производными для получения амидов):
	  - CH₃NH₂ + CH₃COOH → CH₃C(O)NHCH₃ (метилацетамид) + H₂O

---

**Получение аминов:**

- **Из галогеналканов**
	  - CH₃Br + 2NH₃ → CH₃NH₂ + NH₄Br

- **Из нитроалкана и атомарного водорода**
	  - CH₃NO₂ + 6H⁰ → (Zn/Fe + HCl = Zn/FeCl₂ + 2H⁰) CH₃NH₂ + 2H₂O

- **Из спирта**
	  - C₂H₅OH + NH₃ → (Al₂O₃) C₂H₅NH₂ + H₂O

## Анилин / фениламин

Ароматический амин («дохлый» амин — см. силу аминов), очень слабое основание.

---

**Реакции и взаимодействия анилина:**

- **Реакция горения**
	  - C₆H₅NH₂ + O₂ → CO₂ + H₂O + N₂

- **Взаимодействие с сильными кислотами**
	  - C₆H₅NH₂ + HCl → [C₆H₅NH₃]Cl (хлорид фениламмония)

  **Схема:**
  ```
  C₆H₅–NH₂ + HCl → [C₆H₅–NH₃]⁺Cl⁻
  ```
  - [C₆H₅NH₃]Cl + NaOH → C₆H₅NH₂ + NaCl + H₂O

- **Взаимодействие с бромной водой**
	  - C₆H₅NH₂ + 3Br₂ → C₆H₂Br₃NH₂ (2,4,6-триброманилин, белый осадок) + 3HBr

  **Строение 2,4,6-триброманилина:**
  ```
        NH₂
        |
    Br—C   C—Br
      //   \\
     C       C
      \     /
       C—Br
  ```

---

**Получение анилина:**

- **Из нитробензола** (реакция Зинина)
	  - C₆H₅NO₂ + 6H⁰ → (Zn/Fe + HCl) C₆H₅NH₂ + 2H₂O

- **Из хлорбензола**
	  - C₆H₅Cl + 2NH₃ → (t, p) C₆H₅NH₂ + NH₄Cl

---

**Цепочки реакций:**

- CH₄ → CH₃NO₂ → CH₃NH₂ → [CH₃NH₃]OH → [CH₃NH₃]Cl → CH₃NH₂ → N₂

- Al₄C₃ → CH₄ → CH₃Cl → C₂H₆ → C₂H₅Br → C₂H₅NH₂ → [C₂H₅NH₃]₂SO₄ → [C₂H₅NH₃]Cl → [C₂H₅NH₃]NO₃ → C₂H₅NH₂ → N₂

- CH₃COOH → CH₃COONa → CH₄ → C₂H₂ → C₂H₄ → C₂H₅Cl → C₂H₅NH₂ → [C₂H₅NH₃]HSO₄ → C₂H₅NH₂ → CO₂

- CaC₂ → C₂H₂ → C₂H₆ → C₂H₅Cl → C₂H₁₀ → C₄H₁₀Br → C₄H₉NH₂ → [C₄H₉NH₃]Cl → C₄H₉NH₂ → H₂O

- CaC₂ → C₂H₂ → C₂H₄O → CH₃COOH → CH₃COONa → CH₄ → CH₃Cl → CH₃NH₂ → [CH₃NH₃]₂SO₄ → [CH₃NH₃]Cl → [CH₃NH₃]NO₃ → CH₃NH₂ → N₂

- CH₄ → CH₃NO₂ → CH₃NH₂ → [CH₃NH₃]OH → [CH₃NH₃]Cl → CH₃NH₂ → N₂

- C₂H₂ → бензол → нитробензол → анилин → [C₆H₅NH₃]Cl → C₆H₅NH₂

- C₂H₂ → X → C₆H₅NO₂ → C₆H₇N → C₆H₈NCl → C₆H₇N
