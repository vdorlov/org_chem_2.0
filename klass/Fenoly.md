# Фенолы

#кислородосодержащая_органика

Фенол (C₆H₆O), он же карболовая кислота. Кристаллы с едким запахом, ядовиты, вызывают ожоги, обладают антисептическими свойствами.

---

**Общая формула:**
- C₆H₅OH

**Строение фенола:**

```
      OH
      |
  H—C   C—H
    //   \\
   C       C
    \     /
     C—C
      |
      H
```

---

**Гомолог:**

```
      OH
      |
  H—C   C—CH₃
    //   \\
   C       C
    \     /
     C—C
      |
      H
```

(метилфенол / крезол)

**ВАЖНО!** Не путать с бензиловым спиртом / ароматическим спиртом (C₆H₅–CH₂OH). Бензиловый спирт по свойствам похож на этиловый спирт.

---

**Изомерия фенолов:**

| Вид изомерии | Описание | Пример |
|---|---|---|
| **Структурная** |  |  |
| **1. Изомерия положения заместителей (в бензольном кольце)** | Самый важный вид для фенолов. Заместители (например, CH₃, OH, NO₂) могут находиться в *орто-*, *мета-* или *пара-*положении друг относительно друга. | Для **метилфенола (крезола)** C₇H₈O существует три изомера:<br>• **орто-крезол** (1-метил-2-гидроксибензол)<br>• **мета-крезол** (1-метил-3-гидроксибензол)<br>• **пара-крезол** (1-метил-4-гидроксибензол) |
| **2. Изомерия углеродного скелета** (в боковой цепи) | Возможна, если углеводородный радикал, связанный с кольцом, имеет разветвления. Встречается реже, чем изомерия положения. | Пример для C₉H₁₂O:<br>• **пропилфенол** (C₆H₄(OH)–CH₂–CH₂–CH₃)<br>• **изопропилфенол** (C₆H₄(OH)–CH(CH₃)₂) — разное строение радикала. |
| **3. Межклассовая изомерия** | Фенолы (ароматические спирты) изомерны некоторым ароматическим спиртам (где OH не в кольце, а в боковой цепи) и простым эфирам. | Для C₇H₈O:<br>• **Метилфенол (крезол)** (CH₃–C₆H₄–OH, OH в кольце)<br>• **Бензиловый спирт** (C₆H₅–CH₂–OH, OH в цепи)<br>• **Метилфениловый эфир (анизол)** (C₆H₅–O–CH₃) |

---

**Реакции и взаимодействия:**

- **Взаимодействие с натрием:**
	  - C₆H₅OH + Na → C₆H₅ONa (фенолят натрия) + H₂

- **Взаимодействие с щёлочью:**
	  - C₆H₅OH + NaOH → C₆H₅ONa + H₂O

- **Нитрование (реакция с концентрированной азотной кислотой)** с образованием тринитрофенола / пикриновой кислоты (если кислота разбавленная, то заместится только 1 атом водорода):
	  - C₆H₅OH + 3HNO₃ (конц.) → C₆H₂(NO₂)₃OH (пикриновая кислота) + 3H₂O

  **Строение пикриновой кислоты:**
  ```
        OH
        |
    O₂N-C   C-NO₂
      //   \\
     C       C
      \     /
       C—NO₂
  ```

- **Реакция с бромной водой** с образованием 2,4,6-трибромфенола:
	  - C₆H₅OH + 3Br₂ → C₆H₂Br₃OH (2,4,6-трибромфенол) + 3HBr

  **Строение 2,4,6-трибромфенола:**
  ```
        OH
        |
    Br-C   C-Br
      //   \\
     C       C
      \     /
       C—Br
  ```

- **Образование простого эфира** (реакция фенолята натрия с хлоралканом):
	  - C₆H₅OH + C₂H₅Cl → C₆H₅OC₂H₅ + HCl

- **Образование сложного эфира** (реакция фенолята натрия с альдегидом):
	  - C₆H₅ONa + CH₃–C(=O)Cl → C₆H₅O–C(=O)CH₃ (фенилацетат) + NaCl

- **Разрыв бензольного кольца:**
	  - C₆H₅OH + 3H₂ → (Ni, t) C₆H₁₁OH (циклогексанол)

- **Взаимодействие с формальдегидом:**
	  - C₆H₅OH + HCHO → (HCl, H₂SO₄) HO–C₆H₄–CH₂OH (салициловый спирт)

- Фенол — кислота, поэтому с органическими кислотами реакции нет.

---

**Получение фенола:**

- **Из хлорбензола:**
	  - C₆H₅Cl + 2NaOH → (350 °C) C₆H₅ONa + NaCl + H₂O
	  - C₆H₅ONa + HCl → C₆H₅OH + NaCl

- **Из бензолсульфоната натрия:**
	  - C₆H₅–SO₃Na + NaOH → (300 °C) C₆H₅ONa + Na₂SO₃ + H₂O

- **Из бензойной кислоты:**
	  - C₆H₅–COOH → (NaOH, Cu, t) C₆H₅OH + CO₂

- **Получение из анилина:**
	  - 1 этап — диазотирование:
	    - C₆H₅–NH₂ + NaNO₂ + 2HCl → C₆H₅–N₂Cl (хлорид бензолдиазония) + NaCl + 2H₂O
	  - 2 этап — гидролиз соли:
	    - C₆H₅–N₂Cl + H₂O → (t) C₆H₅–OH + N₂↑ + HCl

---

**Цепочки реакций:**

- метан → ацетилен → бензол → хлорбензол → фенол → трибромфенол
- метан → хлорметан → этан → хлорэтан → пропан → хлорпропан → гексан → бензол → хлорбензол → фенол → пикриновая кислота
- CH₄ → C₂H₂ → C₆H₆ → C₆H₅Cl → C₆H₅OH → C₆H₅ONa → C₆H₅OC(=O)CH₃
- карбид алюминия → метан → ацетилен → бензол → хлорбензол → фенол → фенолят натрия → этилфениловый эфир
