## 8.2. Задание 32. Цепочки превращений

### Что проверяет это задание?

Задание 32 проверяет знание **генетической связи между классами органических веществ**. Это не просто «знать реакции», а уметь:
- Определить класс вещества по его формуле
- Выбрать правильную реакцию для данного превращения
- Записать структурную формулу органического вещества
- Указать условия реакции
- Уравнять уравнение

### Требования к оформлению (по критериям ФИПИ)

1. **Структурные формулы** для всех органических веществ. Молекулярные формулы (например, C2H6O вместо CH3CH2OH) **не принимаются**.

2. **Уравнения реакций** с расставленными коэффициентами. Без коэффициентов — потеря балла.

3. **Условия реакций** (t°, катализатор, H+/OH−, свет и т.д.). Можно не писать условия, если они не являются ошибкой. Указание неверных условий считается ошибкой.

4. **Преимущественно образующиеся продукты**. Если реакция может идти несколькими путями, нужно указать основной продукт.

### Почему структурные формулы так важны?

В органической химии одна молекулярная формула может соответствовать многим разным веществам (изомеры). Например, C2H6O может быть этанолом CH3CH2OH или диметиловым эфиром CH3OCH3 — совершенно разные вещества с разными свойствами. Структурная формула однозначно определяет вещество.

### Алгоритм решения задания 32

```
Шаг 1: Прочитать условие и определить исходное вещество и конечный продукт
    ↓
Шаг 2: Определить классы веществ (начальный и конечный)
    ↓
Шаг 3: Оценить, меняется ли число атомов углерода
    ↓
Шаг 4: Выбрать маршрут превращения по таблице генетической связи
    ↓
Шаг 5: Для каждого перехода записать:
        - Структурную формулу органического вещества
        - Реагенты
        - Условия (если нужно)
        - Уравненное уравнение
    ↓
Шаг 6: Проверить:
        - Все ли формулы структурные?
        - Уравнены ли коэффициенты?
        - Указаны ли все условия?
        - Сохраняется ли число C (если не предусмотрено изменение)?
```

### Пошаговый разбор алгоритма

**Шаг 1: Определить исходное и конечное вещества**

Прочитайте внимательно условие. Часто вещества даны формулами или названиями. Если название — сразу нарисуйте структурную формулу.

**Шаг 2: Определить классы**

| Формула / признак | Класс |
|-------------------|-------|
| CnH2n+2 | Алкан |
| CnH2n (одна C=C) | Алкен |
| CnH2n−2 (одна C≡C) | Алкин |
| CnH2n−6 | Арен |
| CnH2n+1Hal | Галогенпроизводное |
| CnH2n+2O (одна OH) | Спирт |
| CnH2nO (CHO) | Альдегид |
| CnH2nO (>C=O, не CHO) | Кетон |
| CnH2nO2 (COOH) | Карбоновая кислота |
| CnH2nO2 (COOR) | Сложный эфир |
| CnH2n+3N | Амин |
| CnH2nO2 (жир) | Жир (сложный эфир глицерина) |

**Шаг 3: Оценить изменение числа атомов C**

Сравните число атомов углерода в начальном и конечном веществах:
- Если одинаково → цепь сохраняется, ищите реакции без изменения C
- Если увеличилось → возможно: KCN, реакция Вюрца, реактив Гриньяра + CO2
- Если уменьшилось → возможно: реакция Гофмана, декарбоксилирование

**Шаг 4: Выбрать маршрут**

Используйте таблицу генетической связи. Обычно есть несколько возможных путей — выбирайте самый прямой и логичный.

**Шаг 5: Записать уравнения**

Для каждого перехода:
1. Напишите структурную формулу органического вещества (не молекулярную!)
2. Напишите реагенты над стрелкой
3. Напишите условия (t°, катализатор) под или над стрелкой
4. Уравняйте уравнение

**Шаг 6: Проверка**

Проверьте каждый пункт чек-листа. Это занимает 1–2 минуты, но позволяет избежать глупых потерь баллов.

### Типичные ошибки и как их избежать

| Ошибка | Последствия | Как избежать |
|--------|-------------|--------------|
| Молекулярные формулы вместо структурных | 0 баллов | Всегда писать структурные формулы; проверить перед сдачей |
| Пропуск коэффициентов | –1 балл | Проверить баланс атомов и зарядов |
| Отсутствие условий реакции | Может быть не критично | Условия можно не писать, но если пишете — только верные |
| Неправильный выбор KOH (водный/спиртовой) | Неверный продукт | Водный → замещение (спирт); спиртовой → элиминирование (алкен) |
| Неправильная температура дегидратации | Неверный продукт | 170 °C → алкен; 140 °C → простой эфир |
| Неучёт изменения числа C | Неверная цепочка | Проверять число C на каждом шаге |
| Забывание о таутомерии (алкин → альдегид) | Неверный продукт | Помнить: еноль → карбонильное соединение |
| Смешение условий для бензола и толуола | Неверный продукт | FeCl3 → кольцо; hν → боковая цепь |
| Окисление 1° спирта до кислоты вместо альдегида | Неверный продукт | CuO, t° → альдегид; KMnO4, H+, t° → кислота |

## 8.3. Задание 33. Органическая задача

### Что проверяет это задание?

Задание 33 проверяет умение проводить **химические расчёты** на основе уравнений реакций органических соединений. Здесь обычно одна реакция или простая последовательность, и основной акцент — на правильное применение химических расчётов.

### Основные типы задач

#### Тип 1: Задача на выход продукта реакции

**Суть**: Дано: масса (или объём) исходного вещества и выход реакции (в %). Найти: массу (или объём) продукта.

**Алгоритм решения:**

1. **Записать уравнение реакции** (уравненное)
2. **Найти количество вещества** исходного реагента: n = m / M
3. **По уравнению найти теоретическое количество** продукта
4. **Рассчитать теоретическую массу** продукта: m(теор.) = n(теор.) × M
5. **Применить выход реакции**: m(практ.) = m(теор.) × η / 100%

**Формулы:**
- n = m / M
- η = m(практ.) / m(теор.) × 100%
- m(практ.) = m(теор.) × η / 100%

#### Тип 2: Задача на массовую долю вещества в смеси

**Алгоритм решения:**

1. **Записать уравнение реакции** (только для реагирующего вещества!)
2. **По данным о реагенте найти количество** реагирующего вещества в смеси
3. **Найти массу** реагирующего вещества
4. **Рассчитать массовую долю**: ω = m(вещества) / m(смеси) × 100%

**Важно**: Не все вещества в смеси могут реагировать! Например, в смеси этилена и этана только этилен реагирует с бромной водой.

#### Тип 3: Задача на избыток/недостаток реагента

**Алгоритм:**

1. Записать уравнение реакции
2. Рассчитать n для каждого реагента
3. Определить соотношение n1 / k1 и n2 / k2
4. Меньшее соотношение указывает на лимитирующий реагент
5. Рассчитать продукт по лимитирующему реагенту

#### Тип 4: Задача на определение формулы по продуктам сгорания

**Алгоритм:**

1. Записать уравнение сгорания: CxHyOz + O2 → x CO2 + y/2 H2O
2. Найти n(C) = n(CO2)
3. Найти n(H) = 2 × n(H2O)
4. Найти массу C и H
5. Если m(C) + m(H) < m(вещества) → есть O
6. Найти простейшую формулу
7. Если дана молярная масса → найти истинную формулу

**Пример из реального ЕГЭ:**

При сгорании 17,55 г органического вещества получили 16,8 л CO2 (н.у.), 1,68 л N2 (н.у.) и 14,85 г H2O. При нагревании с водным раствором NaOH вещество гидролизуется, одним из продуктов является пропанол-1.

Решение:
- n(CO2) = 16,8 / 22,4 = 0,75 моль; n(C) = 0,75 моль
- n(H2O) = 14,85 / 18 = 0,825 моль; n(H) = 1,65 моль
- n(N2) = 1,68 / 22,4 = 0,075 моль; n(N) = 0,15 моль
- m(C + H + N) = 0,75 × 12 + 1,65 × 1 + 0,15 × 14 = 12,75 г
- m(O) = 17,55 – 12,75 = 4,8 г; n(O) = 0,3 моль
- n(C) : n(H) : n(N) : n(O) = 0,75 : 1,65 : 0,15 : 0,3 = 5 : 11 : 1 : 2
- **Молекулярная формула: C5H11NO2**

### Чек-лист решения задания 33

- [ ] Правильно записано уравнение реакции
- [ ] Определён лимитирующий реагент (если дано два реагента)
- [ ] Проведён расчёт через количество вещества (n), а не напрямую через массы
- [ ] Учтён выход реакции (если дан)
- [ ] Правильно рассчитана масса раствора
- [ ] Правильно рассчитана массовая доля
- [ ] Единицы измерения проверены
- [ ] Ответ округлён до разумного числа знаков

## 8.4. Задание 34. Комбинированная задача (высший уровень сложности)

### Что проверяет это задание?

Задание 34 — самое сложное в ЕГЭ по химии. Оно проверяет:
1. **Комплексное знание** органической и неорганической химии
2. **Умение работать с многостадийными процессами**
3. **Умение учитывать выход на каждой стадии**
4. **Умение рассчитывать массовую долю в растворе после реакции**
5. **Умение составлять и решать системы уравнений**

> **Важно:** в 2025 году в задание 34 включено понятие **«молярная концентрация»**.

### Типы задач 34

#### Тип 1: Многостадийный процесс с потерями

**Формула:**
η(общий) = η1 × η2 × η3 × ... (в долях, не в процентах!)

#### Тип 2: Расчёт с учётом массовой доли в растворе

**Формула массы раствора после реакции:**
m(раствора после) = Σm(вступивших) – m(осадка) – m(газа)

#### Тип 3: Органика + неорганика (смешанные)

**Алгоритм:**

1. Определить, какие компоненты смеси реагируют, а какие — нет
2. Записать уравнения реакций
3. Ввести переменные (x, y) — количества веществ
4. Составить систему уравнений
5. Решить систему

#### Тип 4: Задача на определение формулы органического вещества

**Пример качественных реакций для определения групп:**
- «Серебряное зеркало» → альдегидная группа (–CHO) или формиат
- Обесцвечивание бромной воды → C=C или C≡C
- Реакция с NaHCO3 (CO2↑) → карбоксильная группа (–COOH)
- Реакция с Na (H2↑) → –OH или –COOH
- Фиолетовое окрашивание с FeCl3 → фенольная группа

### Чек-лист решения задания 34

- [ ] Все стадии процесса учтены
- [ ] Общий выход рассчитан как произведение выходов (в долях!)
- [ ] Масса раствора после реакции рассчитана с учётом осадков и газов
- [ ] При расчёте массовой доли использована масса раствора, а не сумма масс реагентов
- [ ] Система уравнений составлена корректно
- [ ] Ответ проверен на физический смысл

## 8.5. Типичные ошибки в заданиях 32–34

### Ошибки, связанные с непониманием теории

| Ошибка | Почему происходит | Как избежать |
|--------|-------------------|--------------|
| Неправильное определение класса вещества | Не знаются общие формулы | Выучить общие формулы и признаки классов |
| Выбор неверной реакции для превращения | Не понимается генетическая связь | Понимать, какая функциональная группа в какую превращается |
| Непонимание, какое вещество реагирует в смеси | Не знаются качественные реакции | Систематизировать знания о качественных реакциях |
| Ошибки в определении лимитирующего реагента | Не понимается стехиометрия | Всегда сравнивать n(вещества)/коэффициент |

### Ошибки, связанные с небрежностью

| Ошибка | Почему происходит | Как избежать |
|--------|-------------------|--------------|
| Молекулярные формулы вместо структурных (32) | Спешка | Проверить перед сдачей |
| Пропуск коэффициентов | Спешка | Проверить баланс атомов |
| Неправильные единицы (г вместо моль) | Путаница | Всегда проводить расчёт через n |
| Арифметические ошибки | Спешка | Записывать все промежуточные вычисления |
| Неучёт выхода реакции | Невнимательное чтение | Выделить в условии слова «выход» |

### Ошибки, связанные с расчётами

| Ошибка | Почему происходит | Как избежать |
|--------|-------------------|--------------|
| Неправильный расчёт массы раствора | Не понимается, что газ/осадок покидает систему | m(раствора) = Σm(вступивших) – m(газа) – m(осадка) |
| Смешение массы раствора и массы смеси | Невнимательность | Внимательно читать условие |
| Ошибки в расчёте n(O) по продуктам сгорания | Не понимается баланс масс | m(O в веществе) = m(вещества) – m(C) – m(H) |
| Неверный расчёт общего выхода | Думают, что выходы складываются | η(общий) = η1 × η2 × η3 (в долях) |
